# ShadeFlow · 外贸窗饰获客工作台

面向公司内部销售团队，发现海外窗饰企业、整理产品与贸易证据、维护客户需求，并通过公司邮箱开展业务沟通。

当前使用 React、TypeScript、Vite 与独立 Node.js 后端，正式获客默认由 Node.js 直连检索、研究模型和飞书；n8n 保留兼容。本机 SQLite 保存任务、客户副本、业务记录、最新评估及邮件状态。

## 启动与检查

要求 Node.js 24.5+。在项目根目录配置服务端连接，可复制环境示例或使用网页「API 连接」。

```powershell
npm install
npm run dev
```

开发网页：[127.0.0.1:5174](http://127.0.0.1:5174)；API：[127.0.0.1:4311](http://127.0.0.1:4311)。

```powershell
npm test
npm run build
npm start
```

生产构建由 4311 端口提供页面。生产服务不自动加载新构建或后端改动；完成构建后在任务空闲时重启原服务并核对接口。开发模式监听前后端变化。

## 当前能力

- 运营总览：实际新增、待办、需求阶段和来源状态，明细可追溯。
- 获客任务：官网、海关逐票或双来源发现；批量目标、预算、定时计划及可恢复执行。
- 客户库：真实企业、副本同步、证据、最新评分、补充资料与开发进度。
- 客户业务：有原文依据的需求、实际沟通、人工接管和跟进任务。
- 沟通中心：多邮箱、首封自动开发、手动同步邮件、原格式阅读及人工回复。新首封使用简化 LLM 生成、程序固定称呼和账号签名。
- 产品与资料：版本化产品、商务事实与对外使用批准；API 连接维护服务端检索、模型、飞书及海关连接。

「AI 业务员」及客户回信自动接待已确定设计，尚未实现或启用；自动追信、图纸解析与自动技术附件属于后续范围。

## 运行限制

当前是本机单用户版本，服务只绑定 127.0.0.1；后端和电脑需持续运行，关闭网页不停止已启动任务。不要同时启动多个进程操作同一业务数据库。

凭证与 .data/ 保存在服务器侧并排除 Git；邮箱凭证采用系统用户绑定的加密方式。备份应停服务或使用 SQLite 一致性备份，同时保留所需配置与文件。迁移机器或 Windows 用户时重新录入邮箱凭证。

尚无团队登录和公网部署权限体系。搜索、模型、飞书写入与真实发信按各自配置和业务授权执行；测试成功或邮箱连接不授予真实客户发送权限。具体限制见 [架构与运行](docs/architecture.md)。
