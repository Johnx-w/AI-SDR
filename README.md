# ShadeFlow · 外贸窗饰获客工作台

面向公司内部销售团队，发现海外窗饰企业、整理经营与产品证据、维护客户需求，并通过公司邮箱开展业务沟通。

当前使用 React、TypeScript、Vite 与独立 Node.js 后端，获客由 Node.js 直连检索、研究模型和飞书。本机 SQLite 保存任务、客户档案、业务记录、最新评估及邮件状态。客户档案先本地保存，页面优先读取 SQLite，飞书在后台核对同步。

## 启动与检查

要求 Node.js 24.5+。在项目根目录配置服务端连接，可复制环境示例或使用网页「API 连接」。

```powershell
npm install
npm run dev
```

开发网页：[127.0.0.1:5174](http://127.0.0.1:5174)；API：[127.0.0.1:4311](http://127.0.0.1:4311)。

```powershell
npm test
npm run build
npm start
```

生产构建由 4311 端口提供页面。生产服务不自动加载新构建或后端改动；完成构建后在任务空闲时重启原服务并核对接口。开发模式仅前端热更新；修改后端代码或 `.env` 后，在任务空闲时手动重启，避免源码保存中断请求和后台任务。

已配置 SSH 别名 `ai-sdr` 并登录 GitHub CLI（`gh`）的发布电脑可在提交代码后运行 `npm run release`：在独立临时目录检查并构建当前提交，推送当前分支到 GitHub，等待同一提交的 Windows 检查和 Linux 发布测试全部通过后再部署云端。CI 未通过或查询失败时停止发布。`npm run release:check` 检查连接与任务状态，`npm run release:rollback` 回退上一代码版本。云端数据和配置保留，发布失败自动恢复原代码；详见[发布与回退](docs/architecture.md#一键发布与回退)。

## 当前能力

- 运营总览：实际新增、待办、需求阶段和来源状态，明细可追溯。
- 获客任务：官网发现；批量目标、预算、定时计划及可恢复执行。
- 客户库：真实企业、副本同步、证据、最新评分、补充资料与开发进度。
- 自动业务记录：真实来信整理 T1 需求，实际往来同步 T3；跟进任务只读，T4 只记录后续追信，不要求业务员手工录入。
- 沟通中心：多邮箱、首封自动开发、后台增量收信、原格式阅读及人工回复。计划可单独开启首封未回复后第 3 天、第 7 天自动追信；沿用固定线程、语言和账号签名。
- 产品与资料：版本化产品、商务事实与对外使用批准；API 连接维护服务端检索、模型及飞书连接。

上述客户页面精简与自动记录已完成本地实现，云端版本以实际部署为准。「AI 业务员」及客户回信自动接待仍待实现；产品图纸提取候选已支持，自动技术回复及附件仍属后续范围。

## 运行限制

当前是本机单用户版本，服务只绑定 127.0.0.1；后端和电脑需持续运行，关闭网页不停止已启动任务。不要同时启动多个进程操作同一业务数据库。

凭证与 .data/ 保存在服务器侧并排除 Git；邮箱凭证采用系统用户绑定的加密方式。备份应停服务或使用 SQLite 一致性备份，同时保留所需配置与文件。迁移机器或 Windows 用户时重新录入邮箱凭证。

尚无团队登录和公网部署权限体系。搜索、模型、飞书写入与真实发信按各自配置和业务授权执行；测试成功或邮箱连接不授予真实客户发送权限。具体限制见 [架构与运行](docs/architecture.md)。
