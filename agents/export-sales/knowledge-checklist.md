# 四品类出口业务员：知识资料准备清单

本清单用于整理供 Agent 查询及供人工处理的业务资料。未确认内容保持“待核实”；关键问题经可信检索和必要澄清后仍无依据，才按具体需求交人工核对。

## 每条资料的登记与权限

- [ ] 登记资料编号、名称、原始文件或记录来源、适用品类及 SKU；共享政策注明其适用范围。
- [ ] 登记适用市场、客户类型、采购形态及限制条件；不适用的字段注明原因。
- [ ] 登记版本、生效日期、有效期、审核人及审核状态；未知字段保留“待核实”。
- [ ] 标明权限：“已确认可用于自动答疑”“获准起草具体商务承诺但逐封人工审核”“人工专用”或“待核实”；权限未确认时不供自动答疑或具体承诺引用。
- [ ] 保留原文位置及限制条件，使回复能追溯到具体条款；更新后标记旧版本失效，不混用冲突版本。
- [ ] 旧提示词的卖点、尺寸档位、每尺寸数量和地区偏好仅为参考，不据此确认实际供货能力。

## 共享公司资料与出口政策

- [ ] 准备经审核的公司介绍、出口业务范围、品牌名称及对外署名。
- [ ] 明确本公司是从中国向海外 B 端供货的出口卖方，客户是采购方。
- [ ] 制造、安装及服务能力按已确认资料表述；出口供货身份不直接证明自有工厂、海外安装团队或客户采购代理身份。
- [ ] 整理实际供货品类、可供采购形态、供货地区及受限事项；美国、澳大利亚、加拿大、英国是主要市场示例，不作为国家白名单。
- [ ] 明确不接待个人自用消费者；个人姓名、个人邮箱或企业少量样品需求不能单独作为排除依据。
- [ ] 整理经确认的询价资料要求、MOQ 政策、售后咨询入口及权限边界；未确认时先核实，不自行补全，关键缺口持续存在再按需求交人工。
- [ ] 共享说明可介绍已确认的一般出口流程；标准具体交易条件只有适用已审核版本才可起草并逐封人工审核，非标准合同责任或例外申请交人工接管。

## 多官网身份、覆盖范围与公司总目录

- [ ] 建立可扩充的官网与邮箱配置：官网标识、域名、对外品牌名称、准确发件邮箱、批准签名和首封选择优先级。当前确认的三个绑定见 [邮箱路由](mailbox-routing.md)；其他官网以后逐项登记，不能根据域名猜测品类。
- [ ] 将共同报价与签约的交易主体单独登记；对外品牌保持独立，明确每个品牌获准使用的公司介绍、素材和声明，避免从其他官网复制品牌文案。
- [ ] 为每个官网建立经审核的产品覆盖记录，标明产品 ID、品类、市场、适用采购形态、来源、版本、审核人和有效状态。首次开发邮件只依据这些记录选定一个官网邮箱。
- [ ] 建立共同交易主体的公司总产品目录，覆盖可供产品的稳定 ID、名称、所属品类、适用市场、来源、版本和审核状态。目录须能给出“有产品”或经完整核对的“无产品”；未导入、检索失败或覆盖不完整时返回“未知”。
- [ ] 将“官网展示／覆盖产品”“公司总目录有产品”“允许自动回答的规格或能力”分开管理。总目录命中不代表现行价格、MOQ、性能或图纸获准对外发送。
- [ ] 保存每个客户选定的官网邮箱及变更记录；后续所有会话、自动跟进和人工处理后的回复沿用这一邮箱。不同官网重复触达或收件冲突先由人工核实。

## 四个品类的规格资料

### 透气窗：Plantation Shutter

- [ ] 按实木、PVC、铝整理实际系列与 SKU；不添加 PS、复合木等未确认材质。
- [ ] 分清整窗成品与型材、叶片、框扇及配件供货，记录名称、图纸、截面、单位和包装规格。
- [ ] 提供常规窗型、尺寸范围、安装条件及选配说明；异形和特殊工艺列为人工核实事项。
- [ ] 材质性能、适用环境、表面处理及配件兼容性按具体产品文件登记。

### 百叶窗：Venetian / Horizontal Blind

- [ ] 按木、复合木、PVC、铝、PS 整理实际系列、叶片及系统资料。
- [ ] 分别整理 Cut Down 与 Custom Made 的实际尺寸表、裁切限制及安装说明；原材料示例不替代现行规格或 MOQ。
- [ ] 提供型材、帘梁、轨道、梯绳、梯带、调节机构及安装件的型号、单位和配套关系。
- [ ] 明确横百叶归本品类；学校、医院等室内工程的产品资料供室内成品帘 Agent 协作使用。

### 室内成品帘

- [ ] 分别整理卷帘、斑马帘、香格里拉帘、蜂巢帘、布艺帘、罗马帘的实际产品资料。
- [ ] 区分成品、半成品、系统配件、型材、面料、电机等采购形态，横百叶资料引用百叶窗品类。
- [ ] 面料记录成分、幅宽、供货单位、颜色批次及具体遮光、防潮等性能依据。
- [ ] 电机记录适用系统、电压、控制方式、尺寸接口及兼容依据；品牌名称不等于兼容证明。
- [ ] 室内机构工程资料记录项目方、产品要求及已提供的技术文件；认证和特殊项目要求逐项核验。

### 户外遮阳

- [ ] 按防风卷帘、天幕、凉亭、伸缩棚、阳光房遮阳等实际系列整理系统及采购形态。
- [ ] 提供型材、轨道、支架、安装件、传动和控制系统的规格、接口及配套清单。
- [ ] 面料、电机和结构性能对应具体型号及测试文件，保留测试条件和适用限制。
- [ ] 防风、防水、抗 UV 等描述按已确认文件使用，不将某一型号的表现推广到全部产品。
- [ ] 认证、环境适应性和电气兼容性按具体产品及市场文件核验，不凭地区、品牌或品类名称推断。

## 图纸准备、提取审核与外发素材

以下为资料和审核要求；实际解析、检索、附件发送及审批工具尚未接通。

### 文件与图像关联

- [ ] 为原文件、页图和裁切图登记文件资产编号，并关联适用 SKU、部件、图号及图纸版本。
- [ ] 记录页码、视图名称、尺寸标注位置或区域，保持原文件、整页图和局部裁切图可相互追溯。
- [ ] 保存文件内容 hash、现行或已替代状态及替代关系；文件名相同不代表内容或版本相同。
- [ ] 记录图纸来源、权属和适用客户；客户专属图纸与通用产品外发素材分开管理。

### 提取结果与关键参数审核

- [ ] 区分扫描图、扫描 PDF、原生 PDF 和原生 CAD，记录实际采用的 OCR、原生 PDF 解析、CAD 解析或视觉提取方式。
- [ ] 所有自动提取结果均先列为待审候选，保留原始文字、数值、单位、公差和符号，不以格式整理后的内容覆盖原文。
- [ ] 每个候选参数关联原图的页码、视图、标注位置与相应部件；箭头、尺寸线或多视图对应不清时保持待核实。
- [ ] 提取候选值与人工审核后值分别保存；记录审核人、时间、依据、适用范围及结论，保留修正前后的差异。
- [ ] 制造尺寸取自明确标注且已审核的资料；不凭像素、图像缩放比例或透视外观推算，缺失尺寸交人工核实。
- [ ] 客户图纸中的结构、尺寸和性能属于客户要求，不证明我方可供货、可兼容或已经完成工程校核。

### 原图审核与外发许可

- [ ] 分别记录参数审批、原图技术审核、外发许可及受众范围；某项参数已审不代表整张图已审或允许外发。
- [ ] 外发素材明确允许哪些客户或受众使用；内部图、客户专属图及局部裁切图均按各自授权核对，裁切不自动解除原文件限制。
- [ ] 文件、图纸版本或内容 hash 更新后重新核实相应批准，旧版本批准不直接继承到新文件或新参数。
- [ ] 无可用文件不声称“已附图”；发送前核对对应版本、许可、适用客户及实际附件，发送结果以渠道记录为准。
- [ ] 关键参数未审时不在自动回复中当作已确认值引用；外发许可缺失时不发送内部原图替代说明。
- [ ] 人工审核图纸或参数不等于交回 Agent；已由人工负责的需求仍须人工明确选择后续接待归属。

## 报价资料、单封审核与人工接管

- [ ] 整理经审核可供 Agent 起草标准条款的价格表、币种、计价单位、适用产品、市场、数量范围、版本、有效期及报价计算依据，并与人工专用资料分开。
- [ ] 成本、折扣底线、非标准客户专属条款和合同责任文件按人工专用权限保存；不把历史个案当作现行议价权限。
- [ ] 所有包含具体商务承诺的完整邮件逐封人工审核；标准报价请求本身不触发人工接管，越权议价、特殊付款、非常规定制等才按确认范围接管。
- [ ] 缺少价格资料时保持待核实，Agent 不估算价格、运费或成交条件。
- [ ] Agent 可整理询价所需的 SKU、尺寸、数量、目的地、采购形态及未确认事项；依据不足时先澄清或核实，不编造具体条款。
- [ ] 保存每封人工审核的完整邮件版本、适用需求、所引用条款版本、收件人与审核结论；修改内容后重新审核，不把一次批准延续到新报价。
- [ ] 单封审核不改变接待归属；真正人工接管后，报价完成、人工发出邮件或事项处理完毕均不自动恢复 Agent 接待，须记录人工的明确交回选择。

## 样品、包装与物流

- [ ] 提供已确认的样品申请资格、可供样品形式、申请步骤及限制条件。
- [ ] 样品费用、运费金额、减免或返还等具体交易条件只按适用已审核政策起草并逐封人工审核；越权减免或赔付转人工接管。
- [ ] 按 SKU 提供常规包装、装箱单位、标签、保护要求及可提供的包装文件。
- [ ] 定制包装、客户品牌标签或特殊文件要求标记待人工核实，保留客户原始要求。
- [ ] 提供已确认的一般运输方式和所需收货信息，区分通常流程与本次订单承诺。
- [ ] 本次运费金额、常规生产交期和运输时效仅在有适用已审核依据时起草并逐封人工审核；特殊或保证到货承诺缺乏依据时不擅自答应。
- [ ] 使用实际确认的包装、重量、体积和目的地资料；缺项保持待核实，不填推测值。

## 脱敏成交与丢单案例

- [ ] 每例包含客户经营角色、市场、采购形态、具体产品、客户诉求、回复及实际结果。
- [ ] 保留每轮推进目标、异议、转人工原因及处理结果；成交与丢单均收录。
- [ ] 移除客户姓名、邮箱、电话、合同编号等识别信息；专属价格和合同条款按权限分开保存。
- [ ] 案例用于学习沟通节奏，不作为现行价格、MOQ、交期、认证或生产能力的证明。
- [ ] 无证据的成交原因保持未知，不把时间先后或业务员推测记为确定因果。

## 多轮客户事实与每项需求的接待归属

- [ ] 维护统一客户与会话记录，保存采购主体、用途、市场、联系人及其原始来源。
- [ ] 每项需求单独编号，记录品类、采购形态、客户原文、已确认规格、缺项及当前阶段。
- [ ] 分开记录产品归属与接待归属，允许同一会话中部分需求人工处理、其他独立常规需求由 Agent 接待。
- [ ] 人工交接记录原因、负责人、待处理问题、一次确认是否已发送，以及尚未发送的草稿。
- [ ] 人工处理后明确选择继续人工跟进或交回 Agent，保存适用需求、允许范围、时间及最新指示。
- [ ] 保存人工已批准内容及版本；共同报价、运费和交期承诺关联全部适用需求，防止跨项误用。
- [ ] 回复前读取最新客户邮件及人工回复，合并重复问题；客户修正的信息保留变更来源，不覆盖成无出处的结论。
- [ ] 保存自选跟进节奏、启用状态及适用需求；人工负责的需求不自动催问，其他需求按各自归属处理。
- [ ] 客户拒绝、退订或需求结束后记录对应停止原因；交回 Agent 时重新评估跟进，不补发过期积压内容。

## 单条知识记录模板

以下为待公司填写的空白模板，不是实测数据、已审核政策或供货承诺。

| 字段                     | 待填写内容                                                               |
| ------------------------ | ------------------------------------------------------------------------ |
| 资料编号与名称           | 待公司填写                                                               |
| 原始文件与具体位置       | 待公司填写                                                               |
| 适用品类、SKU 与采购形态 | 待公司填写；不适用时注明原因                                             |
| 适用市场与限制条件       | 待公司填写                                                               |
| 文件版本                 | 待公司填写                                                               |
| 生效日期与有效期         | 待公司填写；未知保持待核实                                               |
| 审核人、日期与状态       | 待公司填写；未经审核保持待核实                                           |
| 可确认内容及其原文依据   | 待公司填写                                                               |
| 自动答疑或人工专用权限   | 待公司审核确定                                                           |
| 缺项与待核实事项         | 据实际情况填写                                                           |
| 替代版本与失效记录       | 据实际情况填写；无记录时不推测                                           |
| 图纸资产与产品关联       | 原文件、页图、裁切图资产编号及 SKU、部件、图号、版本，待公司登记         |
| 标注定位与内容核对       | 页码、视图、标注区域、内容 hash、现行状态，待公司登记                    |
| 提取方式与候选内容       | OCR／原生 PDF／CAD／视觉方式及原始文字、值、单位、公差，自动候选保持待审 |
| 人工审核后参数           | 审核后值与候选值分开；审核人、时间、依据、适用范围及结论，待公司审核     |
| 原图技术审核             | 审核对象、版本、审核人、时间及结论，待公司审核                           |
| 外发许可与适用受众       | 获准外发的具体文件或裁切图、版本、客户或受众及限制，待公司授权           |
| 图纸来源与变更记录       | 公司或客户来源、替代关系、参数修正及批准变更，据实际记录填写             |
