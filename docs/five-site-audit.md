另外修正了一个共通问题：AI 可能把网页引用段落拼接，或移除行内标签旁的空格。现在每项 AI 值通过严格结构化输出携带原文证据，再恢复真实连续引文并校验；不接受凭空引文。不能验证的企业名不覆盖原名；不能验证的主营分析可仅根据已验证的 AI 产品事实做产品线归纳。主营产品偏好不表示实际采购意向，未自动生成客户等级。

这五站的发现主要指向页面规划、证据校验及写入逻辑，并不能据此认定换 API 就能解决全部问题。本轮继续使用 Tavily，未切换到 Firecrawl。现有流程每轮最多读取五个同站 HTML 页面，再按需补抓最多五个新发现或失败页面；超大网站的全部城市目录、动态交互内容和未公开联系方式仍可能不完整。
