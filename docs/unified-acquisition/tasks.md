# 统一获客实施任务

状态为定稿设计的本地任务拆分，均待实施。共同需求与业务规则见[实施规格](spec.md)。依赖表示必须先有可运行的行为，表格顺序不要求串行开发。

| 任务 | 前置 | 用户能验收的结果 |
| --- | --- | --- |
| 01 官网准入 | 无 | 从任务入口读到主体正确的合格企业 |
| 02 唯一新增与人工补证 | 01 | 重复候选、补录、重试由同一套主库结果计数 |
| 03a 获客计划支持所有国家 | 无 | 创建和编辑全球计划，按已保存范围到期执行 |
| 03b 跨批累计新增 | 02、03a | 一个目标跨国家、跨批持续累计 |
| 04 执行中断与恢复 | 03b | 重启后从已确认进度继续，记录与计数可核对 |
| 05 地图发现对照 | 02 | 地图发现的企业也走同一准入和去重 |
| 06 放量校准与运行报告 | 04、05 | 可判断哪些路径可以放量、剩余时间能新增多少家 |

### 01 官网准入

运营从立即或定时任务收到有出处的“收录／排除／待核实”结果。将现有身份复核、产品抽取和准入判断接在所有写入路径前；复用原文，限制同一缺口的补查次数。证据不充分的候选让出队列。以交接案例的冻结原文预先标注真值，在现有 native-acquisition 与 customer-eligibility 套件加入回归。

- [ ] VD 和 Hillarys 分别核对经营主体、域名与主营，合计 2 家。GaLaBau 主办方排除；只有参展页的被介绍企业待核实。检查档案列表、原文和执行记录。
- [ ] 为准入表逐行配正反例，包括纯自产配件与经销、成品优先、家用与商业项目、遮阳伞和挡烟帘、客户自备与供货不明；旧目录信息不足时保留缺口。
- [ ] 在采购证据中分别输入明确采购窗帘布、明确否定采购窗帘布、仅采购办公用品，核对三者的需求字段、评级依据和首发选材；仅合格经营事实足以入库。

### 02 唯一新增与人工补证

把立即、定时与“核实并尝试入库”的持久化、读回和新增归属接通。依托现有 batch-jobs、acquisition-review-api 与主库检查，给执行页提供可核对的结果及理由。

- [ ] 两家主体共用一域名但各有独立经营证据时分别入库；同主体换域名或重复命中仍一档。仅有名称近似的候选暂存。并发到达时重读档案、来源和计数与预标结果一致。
- [ ] 缺证候选更正官网后，自动补证成功与人工裁定成功均可入库，保留依据、操作者及时间。人工新增单列，累计总数只增一次，历史轮次计数不变。
- [ ] 写后读回不明时保持待核对。模拟写成功应答丢失和镜像不可用，恢复后各以主库结果计数。已存在客户、多个供货方向及模型给出的评级均不增加新增数。

### 03a 获客计划支持所有国家

本项可独立编排。修改新建和编辑计划的国家选择、API 校验与存储、搜索预览、到期调度、发现和研究的国家匹配。先让全球和单国范围在正常入口走通，再扩展总目标与跨批执行。

- [ ] 从获客计划页面创建一次性“所有国家”计划，保存后刷新并进入编辑，核对范围和时区。用测试时钟触发；保存的计划、实际查询、执行详情三处一致。再从单国编辑为全球，核对下一次重复计划按新范围执行，之前轮次仍显示原范围。
- [ ] 在隔离库注入有原文证据的美国和法国窗饰商（法国在旧 25 国选项之外），另加无关旅游企业。全球计划收录前两家，逐家读回真实属地，旅游企业无新增。用同一输入运行美国计划，仅美国合格企业可新增；两次各用空测试库。
- [ ] 已有单国计划按原时区、原范围触发。空值、无效旧范围及地区字段冲突不能被视为“所有国家”。企业属地未知时保持未知；搜索预览及供应商请求中不能把界面标签当作检索词。

### 03b 跨批累计新增

用户设置目标数即可立即运行或定时开始。后台以同一任务持续调度市场、语言及搜索词。内部批次继承进度，按剩余名额协调并发。展示实际覆盖和剩余，不要求设置角色、国家配额或逐条审核。

- [ ] 隔离数据集预先列出不同国家、两个合格角色和一个个人自用对照。以单个目标执行，验证搜索角色与实际经营角色不同仍按定稿入库，检索国家不能填入未知的企业属地。
- [ ] 用模拟时钟、足量唯一候选与重复项跨越 200 家和内部时限；验证超过单批容量的自定义目标可跨批累计、末批并发时准确停止。网页关闭、服务重启后仍回到同一任务。
- [ ] 已运行的旧任务保持原规则版本和累计结果；稳定夹具核对切换前后。展示当前吞吐与剩余，区分候选耗尽和执行中断。

### 04 执行中断与恢复

在任务页展示用量、暂停原因和“继续”。复用执行游标、原操作查询和供应商队列。复用有效缓存，记录已完成步骤。此项验收用替身及隔离库。

- [ ] A 已入库、B 已抓页待模型、第三条重复 A 时模拟服务重启。恢复执行后，B 不重新抓页，A 只计一次。单独在写成功未读回时中断并重启，两次点击继续，确认调用与读回账均无重复。
- [ ] 检查付费请求结果未知、已派在途返回及缓存失效。列明哪些结果可复用、哪些需核对；以供应商请求日志对账。执行详情显示已完成步骤、剩余目标及未决操作。

### 05 地图发现对照

复用地图原型中适用的发现能力。取得地点线索后定位独立官网，沿用 01、02 的判定与写入。先核账号与可留存字段，记录允许的数据、来源和验证环境。自动定位受限时报告该路径可用能力，官网主量任务继续。

- [ ] 隔离提供方返回独有门店 A、与官网搜索重合的 B 和无法定位独立官网的 C。核对 A、B 各有一档；B 可追两源，C 待核实。多个门店归同主体时再次核对。
- [ ] 用同市场、同品类比较独有合格新增、共同发现、总消耗及每家成本；只读位置编号的模拟不能作为真实账号与定位能力验收。
- [ ] 注入地图错绑、权限不足、暂时限流。核对地图路径状态、已保存进度及官网路径连续性。共享身份核验遭污染时，所有依赖路径暂停自动入库。

### 06 放量校准与运行报告

将每次验收的采样框、独立真值、来源、版本与执行结果关联。先走隔离回归，再用真实运行的小批数据衡量成本与吞吐。由用户自行启动真实获客任务。

- [ ] 自然样本在预筛前抽取并按主体去重，人工盲标、分歧裁决。分别交付自动收录合格率分子、分母和区间、人工无法判断数、漏收原因及官网错绑；挑战组独立报告。99% 作为放量目标；样本不足注明范围并继续校准。
- [ ] 展示各来源的去重新增、自动和人工贡献、单位成本、调用数、缓存命中、小时产量、剩余时间及预计缺口。
- [ ] 销售是否接手、拒绝原因、报价或订单能追到对应企业与记录，缺少记录标未知。最终运行报告同时给出适用范围、实测国家与路径、预期及实际数量、差异，区分模拟通过与真实产量。

交付前从现有测试入口检查立即、定时及人工补录的调用方，并同步实际切换的获客主题和 ADR。生产操作与历史数据处置不属于以上实施票。
