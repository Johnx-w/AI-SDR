# 采集现场配对验收

适用对象为已发现的一方候选官网。此次定向抽样覆盖美国和澳大利亚各 30 个互异官网，每站固定同一页面，四家合作校准另列。每站 Node 直读与受限 Chromium 各读取两次，交叉顺序。证据来自独立盲标官网、既有搜索摘录和试跑，其中 43 家新标注站点的 75 条精确短句已与采集前的一方原始 HTML 逐条核对。另有五家使用试跑标注。

框架层按初始 HTML 的 hydration 和交互特征预先入组，允许服务端直接提供正文。既往失败层有早期阻断、无 HTML、渲染正文缺失及压缩异常。齐备按一次已标注读取计，要求采集报告成功且保留全部预标原文。

基线运行于干净提交 7baefea695a2a3c368000cd78d692b2fcbe9479b、Windows x64、Node 24.22.2、Python 3.12.16、Scrapling 0.5.1、Playwright 1.65.2、Chrome Headless Shell 159.0.8154.6。逐站串行。耗时使用全部读取结果的最近秩 P50 和 P95。RSS 为浏览器和 Python 进程树采样和，可能重复计入共享页。整机用量包含其他桌面进程。

市场样本 120 对，两路均报成功 101，仅 Node 0，仅浏览器 1，两路均未成功 18。独立结构审核发现浏览器报告成功但解析后无正文 24 次，分布于 12 家；另有 ONESOLOMON 压缩乱码和仅留评分与标题的正文。以逐次状态和正文核查分别记录。

两次取得的原始快照哈希变化的站点为 Node 21 家、浏览器 22 家。58 个尝试对的两路原始哈希相同，其中 15 对仅 Node 标注齐备，0 对仅浏览器标注齐备。浏览器在 The Blind Factory 的两次精确短句命中来自 HTML 命名实体 &amp;rsquo; 解码，原始 HTML 已有该句。

框架层正文差异审核中未发现原始正文缺失且两次渲染均重复出现的供货段落。

共 195 个按摘要去重的基线快照，压缩体积 11349290 字节，全部重新解压和校验 SHA-256。
