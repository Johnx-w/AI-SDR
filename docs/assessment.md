# 客户评级与初始开发顺序

当前规则为 `acquisition-v5.0`。评价单位是企业的一项具体供货方向和产品族；成品、材料配件和样本展示分别取证，不跨方向借用经营角色。模型提取官网事实，程序核对引文、来源和产品方向后给出结论。

## 匹配与排序

先核对企业主体、目标产品、市场、客群和必需条件。明确不匹配的新发现企业不建客户档案；主体冲突或必需条件待核实的机会暂停自动开发。一个方向不适合时仍可保留同企业另一个有效方向。

已收录的有效企业按以下规则排序：

| 客户评级 | 同一供货方向的依据                                     |
| -------- | ------------------------------------------------------ |
| A        | 主营产品与对应专业或综合供货角色均已核实               |
| B        | 相关产品已核实，但主营程度或对应经营角色的优先线索较弱 |
| C        | 产品或经营角色尚待核实，或现有机会较弱                 |

匹配等级单独说明产品关联是明确匹配、潜在匹配、待核实或不匹配。优先线索保留主营产品、供货角色、现有供货流程、定制及系统特征等已核实事实和原文来源。年限、网点、案例、定制、联系人及公开采购需求未知不会压低开发优先级，也不补成已确认事实。成品业务可以支持潜在材料供货机会，但不证明材料采购方式或采购意愿。

客户可进入客户库而暂时没有可发送的邮箱；A/B/C 均可进入首封候选。实际发送仍须满足企业身份、可用商务邮箱、产品与内容依据以及触达计划授权。同一企业只要仍有经营事实或必需条件冲突，即使其他产品获 A 级，也暂停自动首封。首封候选先选 A，再选 B/C。过期评级筛选在迁移时清除并暂停相关未完成计划，重新选择 A/B/C 后才能启动，不能因清空筛选扩大收件范围。未回复后的定期邮件联系不在本次规则内。

## 档案与历史

客户档案不因官网未公开年限、采购量、负责人或定制细节而默认显示“待确认／补资料”；真实的主体、产品或强制条件冲突仍列出复核事项。材料采购细节可在业务沟通中确认，不作为获客项目的人工补档前置条件。

每企业保留云端最新评估快照，按保存的事实重算为当前规则，不备份旧值，不保留旧评级兼容分支。评级结果、摘要及实际开发进度同步到飞书；原始事实与来源继续保存。补充真实资料仍可按对应方向重算，不要求销售补齐普通官网缺项。

## 客户档案展示

2026-11-02 取消“最新评估”独立页签，保留系统初评、客户评级及其依据。客户画像首屏帮助业务员快速了解企业经营内容、潜在供货机会和开发理由，完整研究过程按需查看。

优先级、匹配等级和开发理由相邻展示。原“优先线索”分类标签改为两三条具体经营事实短句，说明判断依据；电动产品线等补充经营特征与决定优先级的依据区分表达。

每项已记录供货机会分别展示方向、产品、匹配等级、客户评级和简短理由。默认展开形成当前客户评级的方向，其他方向显示可展开的摘要行，避免把某一方向的 A 级判断套用于所有产品。

供货分析依据该方向的产品和经营角色事实，解释产品如何切入客户现有业务。成品经营支持的潜在材料机会明确区分经营依据与目标材料产品，采购安排保持待沟通；不把潜在机会描述为已确认采购计划。分析复用本地最新快照，无需重新研究客户，各方向独立使用对应经营事实。

供货机会区展示分析和经营事实短句，不提供“查看依据”展开区。“官网证据”提供官网原文及来源；人工确认在所支持的结论旁标明确认人和时间。更多企业资料中的客户行业画像保留经营描述和依据文字，隐藏嵌入的来源行。

客户档案保留“客户画像、官网证据、联系方式、沟通与跟进、原始字段”五个页签。画像按以下顺序组织：

| 顺序 | 区域               | 默认展示与展开内容                                                                                                                             |
| ---- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 需核实提示         | 仅有真实冲突时置顶，说明冲突、实际影响及核实入口。普通官网缺项不作为警告。                                                                     |
| 2    | 企业概况           | 公司标识、名称、官网和国家沿用档案头部；画像展示一句话经营概况、客户类型、服务客群、主要经营产品及“记录已核实信息”入口，其余产品可展开。       |
| 3    | 供货机会与开发理由 | 按方向展示产品和具体理由，主方向展开，其他方向先显示摘要；沿用品类旁已有的浅色评级，不重复显示评级组件。已有公开或人工确认的采购需求单独标识。 |
| 4    | 邮件开发状态条     | 展示由实际收发和需求推进得出的开发状态。                                                                                                       |
| 5    | 更多企业资料       | 服务地区、详细地址、完整企业介绍、经营法人、别名和发现来源按需展开；完整人工确认记录仍可折叠查看。                                             |
| 6    | 资料时间与初评记录 | 官网取证与评估更新时间显示一行；当前评估的原始记录和规则版本放入“初评记录”折叠项。                                                             |

人工改级标记紧贴当前客户等级，自动判断仍可核对，不把客户级人工调整冒充各方向的自动结论。影响判断理解的研究限制在相关结论旁直接说明，其余过程说明收进初评记录。
