# 海关历史数据的网页导入方案

2026-10-21。状态：按用户要求纳入首期的功能方案，尚未实现。用户计划自行取得并导入目标国家历年进口数据；系统部署到云服务器，支持在网页上传、后台处理并关联企业评分。通用需求记录见 [Issue #9](https://github.com/Johnx-w/AI-SDR/issues/9)。

## 用户要准备的数据

需要能定位进口企业的明细数据，不是仅按国家/HS编码汇总的行业统计。每个目标国分别确认是否提供具名买方及逐票/逐笔信息；美国样本有相应结构，不默认澳大利亚等国家完全一样。先用一份小样核对字段，再导入历年文件；无需购买API才能使用获准导出的文件。

### 导入批次信息：网页填写或从文件读取

- 数据供应商、数据集名称、进口目标国、运输方式/覆盖范围。
- 数据覆盖起止日期、供应商数据更新截至日、导出日期；这些日期与交易事件日期分别保存。
- 查询用的产品词、HS条件及其他筛选；是否导出全部匹配结果、是否有行数/分页截断。
- 日期列的定义（进口/到港/申报/装船日期等）、数量/重量/金额字段定义；是否估算值。
- 明细层级：一行是提单、报关单、商品行还是拆分记录；Master/House之间关系及供应商去重口径。

### 数据字段分级

| 字段 | 要求及用途 |
| --- | --- |
| 进口/收货企业名称，及其交易角色 | 企业级关联基本字段；名称匿名/未声明的行可留原始区，但不能生成确定买方 |
| 买方地址、国家/地区；有则提供企业统一ID/归一名 | 强烈需要，降低同名/分支/货代误匹配；只有名称时可导入候选，不能自动确定关联 |
| 交易事件日期与日期类型 | 计算最近进口和观察窗口所需；有明确日期格式，不把导入日当进口日 |
| 完整商品描述；有则提供HS编码及编码版本/层级 | 判断与具体供货机会相关，区分成品、面料、配件及混装商品。只有roller blind关键词或HS大类仍需相关性核实 |
| 稳定的来源记录ID、提单/报关单号及明细行号 | 可靠跨文件去重和独立进口频次所需；记录ID不能自动等同于一票；需明确字段粒度 |
| 相关商品数量和数量单位 | 规模5分的优选依据；PCS/套/米/平方米等分别处理，不混加 |
| 商品净重/毛重、单位及字段适用范围 | 无件数时的可选规模依据；要能确定对应商品，不能拿整票混装/含包装总重当相关产品净量 |
| 发货/供应企业名称、地址、国家；有则提供统一ID | 供应关系和主体核实；发货人不自动等于制造商或竞品工厂 |
| 申报金额、币种、计价口径（如有） | 可选；不作为能够导入的前提，不推算我方利润 |
| 通知方、承运人/货代、港口、箱量/TEU等（如有） | 辅助排除物流角色、判断覆盖；箱量不自动换算产品数量 |

**可以先导入、逐步补全。** 身份/日期/产品等字段足够时，先用于候选发现和近期进口线索。缺唯一单据语义，频率部分未知；缺可比较的数量/重量口径，规模部分未知；不拒收整个文件，也不把缺项补满、按其余项重新放大到15。

官网、采购人员、邮箱、电话不是海关文件必填项；系统在后续官网研究中补充。若数据商有公开联系字段，也须确认所属交易方，不将通知方/货代邮箱归到买方。

## 历史跨度与分批策略

- 已有数年历史均可分批导入，按国家、年度/月份和来源管理；增量文件持续追加，不用每次覆盖整库。
- 建议先用最近一段的小样完成字段映射和质量预览，确认口径后再上传历年批次。大批量优先UTF-8 CSV，普通规模也支持XLSX；不同数据商的原列名通过网页映射，无需用户手工改成同一模板。
- 默认展示最近12个月的相关进口量、独立进口票数、活跃月份、最近进口日期及年度趋势；更早历史用于连续性/变化观察，不把数年累计与一年进口量直接对比。
- 覆盖不完整或更新截止日过旧时，展示实际可观察时间范围和缺口；不能按“导入了文件”推断全市场完整，也不能把缺失月份当无采购。

## 网页操作流程

入口：客户库 → 海关数据 → 导入文件。

1. **选择文件。** 支持CSV/XLSX及多个分批文件，显示大小/格式限制；可以选择工作表。较大文件按服务容量分批；分片上传/续传能力纳入上传接口设计。
2. **填写批次信息、映射字段。** 保存不同供应商/国家的映射方案；预览样本和单位、日期解释。
3. **导入前预检。** 展示行数、缺失字段、匿名企业、产品描述截断、异常日期/单位、疑似重复以及本批可以计算哪些评分项。
4. **确认并后台处理。** 网页显示上传、解析、校验、去重、入库、主体匹配及汇总各阶段；全部文件上传成功并创建任务后，可以关闭网页，任务继续在服务器执行。
5. **查看结果。** 展示新增/更新/重复/异常贸易记录数、匹配企业数、待人工核实及评分受影响数；提供带原行定位的异常报告，可修正后重导。

贸易数据成功导入与获客研究分开计数。批量补官网/评分作为可配置任务，沿用搜索与研究上限，不因导入百万行便无上限调用AI或搜索。既有客户只补证据/重评，新候选达到销售交接条件后才计新增客户。

## 云服务器处理方式

浏览器负责选文件、上传、字段映射和查看进度；云端保存原文件/批次并异步解析到数据库。数据库按买方身份、国家、日期和产品索引查询。全量原文件不需要每次发给模型；AI仅在必要的产品分类/主体研究步骤读取授权的相关片段。

需配置持久化文件存储、数据库、后台任务执行、任务恢复和备份。不能只放进服务临时目录或一次HTTP请求内全部处理。文件大小、分片大小、并发及单批行数按部署资源配置并在页面明示；不预先承诺任意大小或任何服务器都能实时处理数年全量。

管理/有授权的账号可上传或处理原始贸易数据；普通业务员查看其权限内客户关联摘要。上传和重评留操作记录；API密钥仅在服务端，不需要浏览器获取供应商API权限才能上传文件。

### 后端接口约束（实施时采用现有项目约定）

以下为建议接口形态，尚未实现：

- 创建上传会话、查询已上传分片、续传与完成文件；服务端返回稳定upload_id。
- 创建预览：指定文件/工作表/列映射和批次信息，返回preview_id、异常及可计算项。
- 确认导入：提交preview_id，返回import_job_id。确认操作需幂等，重复点击不产生重复导入。
- 查询任务/分页错误明细；取消/重试任务；取消后保留可审计的已处理范围。
- 查询批次覆盖和客户关联贸易摘要；对不确定主体发起人工匹配/撤销。

文件指纹避免原文件重复上传产生重复批次；稳定来源记录ID与明细键识别不同文件中的重叠。缺标识时相似行仅标疑似，不能按“同日同双方”直接删除或把行数当独立票数。数据商更正记录保留版本；撤销批次只移除该批来源贡献，保留其他批次证据和原客户档案，重算受影响汇总/评分。

## 海关15分需要什么

按用户最新使用方式，将I定义为“海关采购表现”；建议拆分为：

| 子项 | 满分 | 数据前提与输出 |
| --- | ---: | --- |
| 相关进口规模 | 5 | 同产品/可比较单位及观察窗口下的数量或可靠重量；记录实际汇总口径 |
| 进口频率与持续性 | 6 | 去重后的独立进口票数、活跃月份及时间分布；一票多商品行不重复加次数 |
| 最近进口时间 | 4 | 主体和产品匹配后的最近事件日期；同时展示数据覆盖截至日 |

用户已认可这三项共15的方案。具体产品/单位、票数与日期参数在实施时按样本口径落成固定版本配置；不会让AI临时决定，也不要求公司先设计算法。不同国家、产品、单位不可直接混排或用导入批次内随机百分位给分。最终核对入口见 [首期汇总](acquisition-final-review.md)。

“进口频率”是运输/申报记录的频率，不等同真实订单频率；一单可拆多票，多单也可合票。前次对话中“采购次数”应按该可观察口径修正。公开求购及已成交记录仍可展示为业务信号，不因一条求购就替代数量和频次取得海关15满分。

只匹配到一条记录时可以显示真实进口证据，不自动给15；关键字段缺失保存分项未知。多个部分缺失时展示可支持小计和缺项，不用0表示已证实没有采购。所有假设满分仅用于既有校准情景，不能写进真实记录。

## 供应商可直接接收的字段说明

> 请按目标国家分别提供企业级进口明细CSV或Excel，包含进口/收货方名称、地址及交易角色，日期和日期类型，稳定来源记录ID、提单/报关单及商品明细标识，完整商品描述、HS编码，商品数量及单位、净/毛重及单位，发货方名称/地址/国家。若有企业归一ID、金额/币种也请提供。请说明每行粒度、单据和明细关系、更新截至日、实际覆盖和筛选条件，确认是否全量导出及有无截断，并确认允许保存到本公司的云端内部系统用于客户匹配和评分。若某国只能提供汇总统计或隐藏进口企业，请单独标明。

## 首期验收

网页可以完成选择文件至看到导入结果；关闭网页不终止已提交的后台任务；服务重启可恢复或明确提示可重试范围；重复文件/重叠数据不制造重复企业或虚增票数；缺字段能说明可用范围；主体冲突进入人工核实；数据库汇总、机会评分和原始记录之间可追溯。原始贸易明细不逐行同步飞书，飞书只接收相应业务摘要。
