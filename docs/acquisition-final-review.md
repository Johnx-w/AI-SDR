## 1. 首期最终交付

**一个供公司内部使用、部署到云服务器的网页获客系统。** 管理员配置持续运行的获客计划，系统准备潜在企业及其供货机会、证据和联系入口，负责人分配后业务员沟通。面向企业买方，不要求必须高利润；本地经销商、零售供应安装商、制造商均按具体供货方向判断。

闭环：**发现企业 → 核实主体和官网 → 去重归档 → 研究产品/角色/联系方式 → 识别供货机会 → 评分与补资料 → 可交接 → 负责人分配 → 销售沟通与反馈。**

供货方向分别评价：窗饰成品、材料配件、样本册/展示资料。实际目标产品按公司已确认供应能力配置，未知规格/MOQ不虚构。

## 2. 日常网页怎么操作

四个主要入口：

1. **获客计划**：国家/区域、供货方向、目标角色、关键词、来源、每轮新增数量、定时安排、运行上限。
2. **执行记录**：进度、产出、更新、重复、待核、失败、资源消耗、暂停/继续与结束。
3. **客户库**：详情、筛选、分配/转交、人工录入、海关导入、导出；业务员看本人客户。
4. **待处理**：主体/重复冲突、缺资料、异常导入、评分待补和同步失败。

详情给销售看：这是谁、经营什么、可能向我方买什么及依据、公司级联系入口、建议沟通切入点、需要确认的问题、有则显示历史沟通/跟进。

联系方式优先官网公开商业邮箱、办公电话或联系表单。采购人员有明确公开职位就附上，没有也可交接。普通手机号不自动当WhatsApp；公开联系人不自动当最终采购决策人。

## 3. 数量、调度和权限

- 每轮目标N表示**新增、去重后、首次符合交接条件的企业数**。网页/贸易行/候选数、已有客户更新、多机会不充当新增企业。
- 数量目标与调用/时长/容量上限分别设置。达到上限仍不足N时显示部分完成、实际成果与原因，由负责人决定是否继续。
- 暂停在当前企业可安全保存后生效，恢复接着做；结束本轮为单独操作。
- 同一计划尚未完成不堆新轮；多个错过时点只补最近一次。不同计划按到期先后排队，受全局容量限制。
- 主体明确自动归档，不确定保留疑似重复。重复发现补证据，合并保留历史并可撤销。
- 业务状态在网页修改，飞书以同步查看为主；首期不默认支持飞书任意改列后自动回写网页。
- 普通销售不能查看全库、原始海关文件或平台密钥；可看自己客户所需的授权摘要。转交留记录。

## 4. 评分最终核对

### 评价单位与五项权重

对**一家企业 × 一个具体供货方向/产品族机会**评分。企业主表显示最高有效可开发机会及其对应方向，排除/冲突/失效机会不参与汇总。

| 项目 | 满分 | 主要档位/规则 |
| --- | ---: | --- |
| P 产品契合 | 35 | 35：我方具体品类为其核心稳定业务；25：综合业务明确副线；10：充分证实只邻近、关联弱；0：明确无关；证据不足未知 |
| R 采购角色契合 | 25 | 25：专业窗饰供货/经销零售/品牌/分销/供货工程，材料机会可对应相关制造商；20：综合建材/非专营工程中明确供货；10：只安装维修；0：确认无适用角色；未知单列 |
| D 持续经营与承接能力 | 15 | 当前仍经营目标品类并有供货流程后：15为≥5可核网点、≥10实际经销商或≥3具名商业交付项目；10为同主体持续专营≥5年或≥2可区分具体交付案例；5为只有当前供货流程证据 |
| V 可匹配的供货能力需求 | 10 | 与我方供应范围对应的定制需求5；同一机会的电动/自动化或明确工程配套需求另5 |
| I 海关采购表现 | 15 | 用户已认可：相关进口规模5、进口频率/持续性6、最近进口时间4 |
| **合计** | **100** | 不依赖企业近期必须扩张，不设置高利润门槛 |

海关统一主体、产品、单位、单据语义及观察窗口；建议主要看最近12个月，历史另供趋势。进口票数不等于真实采购订单数，一票多商品行不能重复算频次。不同品类/单位的规模档参数由实施落为版本配置，结合实际文件做映射，不让AI自由报分。本轮不再要求用户重新设计海关算法。

### 等级和资料准备

| 结果 | 条件 |
| --- | --- |
| A，优先开发 | 支持分≥75且P≥25、R≥20、D≥5，无已确认硬性障碍；90—94/95—100为A中的更高匹配档 |
| B，可开发 | 支持分60—74且P≥25、R≥20、D≥5，无硬性障碍 |
| C，暂缓 | P/R已知不满足门槛，或事实足够而支持分不足60；仍保留企业/机会与原因 |
| 待核实/待补全 | 主体/关键事实冲突，P/R未知，D资料不足，或联系入口缺失等；标出具体原因 |
| 暂不开发 | 该机会明确不相关、不是企业买方或已确认不能满足强制规格/履约条件；不删除整家企业历史 |

资料不足和不适合分开；工厂/本地门店/面向住宅消费者/缺海关/缺采购负责人不是自动排除项。R描述角色匹配，具体进口/外采方式要另有证据。

海关缺项留未知，显示“已支持分数＋缺项”，不按剩余项比例补成满分；无记录与未覆盖、未导入、未匹配区分。先前90/95案例包含假设海关15，不能作为真实评级写回。

可交接需：身份明确、至少一个A/B机会、至少一种有来源的公司级联系入口，以及匹配依据/未知项/已有历史齐备。高分但缺联系入口继续补资料，不计新增目标。评分不表示成交概率。

## 6. 飞书调整和存量保护

实施时重读当前表结构，备份字段/记录，保留原客户和记录ID，标记存量；新增表/列并适配现有读写、去重、导出依赖；有来源再回填，旧有效资料不被空值覆盖。

先用少量记录迁移核对，再切换同步和隐藏旧列。真实企业不因低分删除；字段物理删除需已完成数据迁移、依赖适配与备份恢复安排。同步失败保留待重试和原因，不显示为成功。

## 7. 完成验收的标准

负责人能在网页配置一次计划并持续运行；三类入口进入同一企业处理链；目标计数准确；同一企业不重复分配；评分可复算且缺项可见；销售拿到可用公司入口和供货依据；海关文件重复导入不虚增频次；暂停/重启可恢复；飞书真实同步可追溯；云端有持久化与备份。

不以抓到多少网页、导入多少行或接口返回成功替代业务闭环完成。详细容量在实际环境测量后设置。
