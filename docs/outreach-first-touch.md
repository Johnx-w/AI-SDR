# 邮件沟通

沟通中心的四个栏目为「邮箱管理」「触达计划」「收件箱」「跟进序列」。业务员在收件箱查看原信、审核草稿、回复和接管，在跟进序列编辑工作区默认策略，在触达计划详情的「客户跟进」页签查看真实首封及各步执行情况。实数查看使用本机快照，正常业务服务按该环境的授权收发邮件。[运行入口和验收](mail-automation/README.md)

## 邮件模板与本机对照演示

演示启动时保存独立构建快照，后续本地构建完成后可重新启动演示查看新版本。`/demo/followups` 为当前运行的客户跟进示例入口，自动定位对应计划。

在「沟通中心 → 跟进序列 → 编辑序列」逐封编辑主题和正文。左侧支持直接写文案、插入公司／产品／品牌变量，以及插入 AI 开场、正文和回复问题。右侧助手可生成整封、主题、开场或附言，也可按指引改写选中的正文，采用后才修改模板。自定义 AI 变量保存名称和写作指引，按每位收件人的经营资料和已核实产品生成。当前序列其他步骤可以复用变量。个性化设置管理该步切入点、回复目标及口吻。

中栏分别选择发件邮箱、客户大类及匹配产品。类别复用现有经营角色及官网事实，同一客户可属于多个有证据的类别；不依据搜索条件、品牌或产品名称归类。系统从完整类别中选取当前邮箱与产品适用的一个真实客户，显示名称、类别、产品、类别原文来源和选择依据，可更换同类样本。没有合格样本时说明缺少的依据，不回退虚构客户。已固定邮箱的客户不跨品牌取样。暂停或额度用尽不妨碍只读预览，但不会授予发送许可。

预览显示正式生成器按本次模板替换后的完整主题、正文和签名。点击“本次使用的写作规则”核对首封、当前步骤、基础规则和产品依据，规则仍从左侧及个性化设置编辑。修改模板、样本、邮箱或步骤后清除旧预览，重新生成后才能看到新结果；迟到响应不覆盖当前选择。第 3、7 天的预览按当前未保存规则依次生成首封和此前步骤作为上下文，不冒充历史实发记录。预览不会保存策略、创建计划、改客户状态或发邮件。保存策略才产生新版本，之后正式起草和跟进排期沿用现有版本冻结规则。

范围、回归及性能证据见[分类预览验收](mail-automation/category-preview.md)。
