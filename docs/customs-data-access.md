# 海关数据接入准备

2026-10-21：为公司内部窗饰外贸获客系统核实数据采购条件。尚未购买服务、申请试用或联系供应商。

## 官方已确认的产品事实

- [Datamyne 定价页](https://www.datamyne.com/our-product/datamyne-pricing/)列出美国贸易数据、全球进出口数据和市场分析等方案，要求联系销售报价，没有公开固定价格；官网提供试用及演示入口。具体试用权限和可用范围待确认。
- [Global Trade Data API](https://www.datamyne.com/our-product/global-trade-data-api/)明确提供业务系统接入能力和公司级贸易汇总，提到商品、交易方、数量、金额等信息。此产品介绍不证明普通订阅包含API，也不证明每个国家和每条记录都有这些字段；需单独取得报价、权限说明与技术文档。
- [提单数据库说明](https://www.datamyne.com/our-product/bill-of-lading-database/)列出按发货人/收货人、地址、商品、国家及日期等条件查询，并支持Excel导出。网页导出能力不等于API额度或后台自动运行权限。
- [官方FAQ](https://www.datamyne.com/our-product/faq/)说明公司名和地址在贸易记录中可能存在多种写法；不同提单还区分发货人、收货人、通知方和物流角色。系统须核实企业身份与记录中的交易角色，不能只按名称相似自动认定买家或竞品制造商。

## 先向公司要什么

1. 当前海关数据采购/使用联系人，以及公司伙伴所用服务的准确产品、订阅覆盖和可提供的资料。请公司安排有权导出的样本或演示。
2. 业务优先市场、主要供货方向，以及已有报关产品名称/HS编码作为查询线索。尚未明确的部分保留待填，不猜测编码。
3. 10—20家真实业务样本：企业官网、已知公司名称、国家/地址；最好包含已知有相关进口的对照企业，由业务判断匹配结果是否正确。
4. 供技术评估的数据样本、接口资料和报价申请。先按真实样本确认适用性，再确定正式购买范围。

## 首份样本后的追加问题

2026-10-21收到的美国进口 `roller blind*` Excel有2234条明细，但缺唯一提单/明细ID、金额和重量单位，部分描述含 `[MORE]`，部分贸易主体未声明。见 [样本核对](customs-sample-findings.md)。请供应商再明确：

- 可否导出唯一记录ID、House/Master提单号、明细标识及完整商品描述。
- `Weight` 的单位、`Container Quantity` 与箱型数量各自的定义；是否有真实/估算金额及对应币种。
- `NOT DECLARED` 的含义、可补充信息范围及主体归一标识。
- 导出样本的实际完整性、分页或导出上限，以及同一记录后续更正的标识方式。

## 对产品设计的影响（建议，待确认）

用户已明确计划自行导入历年目标国进口文件，并要求前端网页入口，已纳入 [海关网页导入方案](customs-import-spec.md)。文件导入不依赖先购买供应商API；数据交付及公司云端保存权限仍按供应商实际授权确认。

- 匹配流程：官网企业身份 → 贸易主体候选 → 名称/地址/国家及关联信息核对 → 匹配可信程度 → 关联记录与汇总。未经核实的候选不作为确定的进口历史。
- 保存记录来源、查询时间、实际覆盖区间、日期、交易角色和数量单位。进口记录的频次与规模只是在该数据覆盖范围内的观察，不等于全部采购。
- 无记录、无覆盖、无权限、查询失败、主体未确认是不同状态，不统一填为“没有进口”。
- 如只能取得合法授权的文件，可先评估文件导入路径；后台自动更新依赖明确可用的API或供应商认可的数据交付方式。
- 进口金额/频次不是我方利润。用户已撤回高利润门槛，系统按业务匹配和可开发性获客，不要求取得利润资料才能导入或评价。
