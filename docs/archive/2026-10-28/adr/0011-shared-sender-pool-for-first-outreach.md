# 首封开发按客户匹配内容，邮箱组成共享发件池

> 历史归档：保留原日期与当时结论，不作为当前实施步骤。现行说明见 [文档导航](../../../README.md)。

2026-10-26 状态更新：首封账号不受官网产品覆盖限制的决定已被 [ADR-0012](../../../adr/0012-route-first-outreach-by-approved-brand-products.md) 替代；以下保留当时决策背景，已准备邮件的发件归属、企业去重与本轮范围边界继续适用。

2026-10-26 用户明确取消给邮箱分配官网或产品身份：首封开发依据客户实际经营情况、来源证据和已审核的产品声明组织内容，触达计划中的邮箱按连接状态、暂停状态、可用额度和发送间隔承担发送，不再依据官网产品覆盖或品牌优先级分配。该决定替代 [ADR-0005](../../../adr/0005-one-mailbox-per-customer-with-shared-catalog.md) 的首次选邮箱部分，避免把同一供货团队的产品能力切成多个邮箱边界；原有品牌事实、共同交易主体和实际邮件往来归属不因此改写。

每封已准备的邮件保留确定的发件账号和署名，实际发送记录沿用该账号；暂停或结果未知时不能静默换账号重发。同一企业跨账号、联系人和计划仍只安排一封首信，产品内容与账号调度分开核对。本轮只实现首封主动开发，不启用收件、自动回复或追信；公司邮箱技术测试与正式计划批准仍是独立步骤。
