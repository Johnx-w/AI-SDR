# 具体商务承诺逐封审核，不等同于人工接管

> 历史归档：保留原日期与当时结论，不作为当前实施步骤。现行说明见 [文档导航](../../../README.md)。

2026-10-27 更新：[ADR-0017](../../../adr/0017-automatic-sending-with-confirmed-information.md) 允许在资料完备且计划已授权的适用范围内免除逐封审核，替代本文件中具体商务承诺一律逐封审核的要求；人工审核与人工接管的区别及超出授权范围的处理原则继续适用。以下保留原决策背景。

2026-10-23 用户调整了原先“正式报价即接管”的边界：若公司提供适用且已审核的版本化价格和政策，品类 Agent 可以起草标准报价、运费、交期、MOQ 与付款条件，但每封含具体商务承诺的完整邮件须由真人按当时版本审核后才可发送。一次审核不改变会话或需求的后续接待归属；超权限议价、特殊付款、非常规定制、反复议价、停滞、持续关键资料缺口及配置命中的大单按需求接管，强烈投诉、赔付、复杂商务、明确签单意向和代理洽谈则整段会话接管。这替代了 ADR-0003 中“正式报价一律接管”的决定。选择分开两种人工参与，是为保留标准业务的连续接待，同时防止一封报价的批准被误用为未来自动承诺的长期授权。
