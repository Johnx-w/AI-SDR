# 邮箱试点与真实主动开发分离授权

> 历史归档：保留原日期与当时结论，不作为当前实施步骤。现行说明见 [文档导航](../../../README.md)。

2026-10-27 更新：真实邮件只读查看及旧试点退役改按 [ADR-0013](0013-read-only-mail-conversations.md) 执行；技术连接不等于发信授权的原则继续适用。

2026-10-23 用户批准先接通一个对外邮箱，但试点收发只限两个公司控制的测试地址、接通后带测试标记的新线程及固定非营销测试内容，不导入历史邮件，也不自动回复真实客户。邮箱连接仅证明技术收发能力，不授予向真实潜客发信的业务许可；产品声明和触达计划尚未审核时，真实主动开发维持关闭。选择这条边界是因为直接复用现有邮箱的真实收件箱或把可发送权限视为营销授权，会使测试误触既有客户或未经批准的商业联系；以后启用真实开发须另行审核产品声明、计划、身份、抑制状态与发送范围。
