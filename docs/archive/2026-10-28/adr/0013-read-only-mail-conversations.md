# 沟通中心统一查看真实邮件并退役旧演示与邮箱试点

> 历史归档：保留原日期与当时结论，不作为当前实施步骤。现行说明见 [文档导航](../../../README.md)。

2026-10-27 后续更新：[ADR-0014](../../../adr/0014-original-mail-format-and-manual-replies.md) 增加原格式阅读、图片加载策略、会话内人工回复和明确匹配的客户沟通记录；以下保留此前只读阶段的决定。

2026-10-27 用户要求清理无用旧实现，并把邮件对话恢复到当前沟通中心；配置邮箱的真实邮件改由同一页面手动只读同步，首次读取最近 30 天，后续增量保存收件箱与可识别的已发件箱。此决定扩展 ADR-0007 的测试线程收件范围并替代旧固定双邮箱试点：不再挂载旧试点接口或后台轮询，原本机数据文件保留；公司内部试发继续使用现有多邮箱触达流程。

邮箱原文与本地会话保存在触达库，查看与标记本地已读不修改原邮箱，也不自动发送、回复、生成采购需求或改写客户业务事实。系统发送记录的服务商接受结果与邮箱中实际同步的邮件状态分别展示，避免把只读收件能力扩大解释成新的发信授权；现有首封审核、客户固定邮箱及企业去重规则继续适用。
