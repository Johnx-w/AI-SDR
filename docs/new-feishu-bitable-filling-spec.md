## T7｜定时触发调度表

目标数据表：`tblH2qBpcxE1LDvW`。

### 一行代表什么

每次实际获客执行占一行，以云端保存的执行记录为依据。长期获客计划继续由系统管理，不将计划本身与某次执行混为一行。

同一计划运行多次，分别记录各次执行；同一次执行补充状态或结果时，按原系统任务编号识别并更新原行。飞书自动编号与原系统任务编号分别保留，任务名称不作为唯一标识。

时间显示统一使用北京时间（`Asia/Shanghai`），实际保存保留原时间精度。未知或没有准确对应关系的字段留空；下文的“留空”是填写说明，不是要写入单元格的文字。

### 状态与数量口径

T7 当前状态选项为「待执行、执行中、已完成、异常终止」。只填写与真实执行状态一致的选项。

| 已核对的系统状态                     | T7 任务状态 | 日志说明                                   |
| ------------------------------------ | ----------- | ------------------------------------------ |
| `completed`，原因为 `target_reached` | 已完成      | 达到新增目标。                             |
| `partial`，原因为 `stopped`          | 留空        | 任务已停止，保留实际新增数量。             |
| `partial`，原因为 `research_limit`   | 留空        | 达到研究上限，部分完成，保留实际新增数量。 |

不将人工停止或达到研究上限统一写为「异常终止」，也不将未达到目标的部分完成写成「已完成」。本次规则不要求新增状态选项。

「实际研究数量」采用执行记录的 `researched`，包含随后被判断为不匹配、待核实或处理失败的候选，不等于新增有效客户数。新增、重复跳过及研究数量分别保留，不相加推算「抓取客户总数」。

历史执行数量采用该轮已保存的统计，不用当前客户库总数回算，也不因后续人工补录或重新核实而改写原轮次的新增数量。

### 共通使用规则

- `{{变量}}` 使用真实资料替换；品牌、产品类别和供货范围须与对应账号及已确认产品资料一致。

- A/B/C 评级不等于采购意向、采购量或发送许可；C 类模板仍只适用于业务匹配且允许开发的客户。首封开发不用于已经进入真实会话的客户。
- 来信回复只追问尚缺的信息，保留客户已提供的规格、数量和用途；不根据官网画像生成采购事实。
- 正式报价模板仅在价格、币种、数量单位、贸易条款及有效期已确认且适用时使用。产品基础介绍不构成价格、规格、MOQ、交期或适配承诺。
- 价格异议先核对比较条件；交期异议区分生产、发货与到货时间，不自动承诺折扣或未经核实的到货日期。

### T4｜跟进任务表

目标 `tbl4hRv1onZMQDhJ`；用户最初的链接 `tblC4rTleU5XmrVK` 实为 T5，不作为任务写入目标。

网页展示关联客户、关联沟通记录、任务类型、计划执行时间、任务状态、使用模板、任务说明、负责业务员，以及飞书自动生成的任务ID。数据库内部编号只用于本地引用和持久同步映射，不写飞书列、不用作页面任务ID。任务类型为邮件触达、WhatsApp触达、网站留言、人工电话外呼；时间按北京时间展示。

状态为待执行、已完成、跳过、终止。跳过与终止均为终态，不计入待办。联系限制和客户新回复仍由执行前核验提示，任务保持待执行，不引入第五种暂停状态，也不自动将受阻任务标为跳过。沟通任务完成需同一客户及渠道的实际沟通证据；电话可使用已确认的通话纪要。本轮替代 ADR-0010 中“任务自动转为暂停”的旧状态行为，实际发送和商务批准要求不变。

### T8｜销售与账号管理
