## 维护规则

- 改业务行为时更新所属主题及必要 ADR，不再新建另一份“最终版”“最新方案”或按日期追加操作教程。
- 一次性调研、迁移和验收报告进入归档，注明日期、范围和是否实测，不把历史数量或费用写成当前事实。
- 实施文档写当前流程；待实现设计明确标注，完成后更新状态，避免把规则资产当作功能已经上线。
- 提示词从共享来源生成，运行 `node agents/export-sales/build-prompts.mjs --check` 核对；协议升级同步 Schema、示例和实际校验。
