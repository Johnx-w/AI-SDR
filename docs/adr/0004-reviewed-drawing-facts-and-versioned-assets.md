# 图纸参数经审核后引用并关联可外发原图

2026-10-22 用户确认将图纸尺寸提取、原图关联、关键参数人工审核和回复附图补入四个出口业务员设计。图纸先保留源文件和修订信息，自动解析只产生待审核候选；人工核实后的参数关联具体产品、部件、图号版本及标注位置，供检索与答复使用，以便回查识别错误和版本差异。

批准参数与批准图片外发分别记录，客户图纸表示客户需求而非我方供货能力。Agent 只提出相应资产编号的附图请求，发送环节重新核对版本、受众权限和真实文件后附送；图纸修订使关联批准和待发草稿重新核验。选择这种分离方式，是为了让尺寸引用、文件发送和销售接待归属各有明确依据，避免一次审核被当作对全部内容和后续动作的授权；审核图纸不自动交回人工已接管的需求。
