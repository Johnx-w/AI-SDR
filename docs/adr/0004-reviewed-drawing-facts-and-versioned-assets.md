# 图纸参数经审核后引用并关联可外发原图

状态：有效；资料准备已实现，参数级批准与自动回复附图待实现。2026-11-10 对照产品文件、产品审核和图纸协议核对。

原文件保留来源及内容哈希，AI 解析只产生待审核候选；目前支持 PDF、PNG/JPG，人工编辑后可纳入产品资料审核。候选不直接作为已确认规格，也不自动成为邮件附件。

后续自动接待须将批准参数关联产品、部件、图纸版本与标注位置，并分别核对参数使用批准和原图外发权限。客户图纸表示客户要求，不能证明我方能力。发送环节重查真实文件、版本和受众；修订后相关草稿与批准重新核验。

这种分离避免一次审核被当作全部参数和文件的发送授权。审核资料也不改变人工接待归属。现有边界见 [资料准备](../architecture.md#上传图纸与产品规格)，目标字段见 [图纸协议](../../agents/export-sales/drawing-protocol.md)。
