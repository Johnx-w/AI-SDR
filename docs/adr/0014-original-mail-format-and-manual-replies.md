# 邮件原格式阅读及会话内人工回复

状态：有效且已有实现；2026-11-10 对照邮件缓存、只读 IMAP、人工草稿与回复发送代码核对。

沟通中心展示邮件原 HTML，并可切换纯文本；内嵌图片按限额处理，外链图片逐封选择加载。HTML 经清理和隔离；增量同步保留原文、消息头与本工作台已读状态，不修改原邮箱已读。

会话内只提供单人回复，沿用当前账号，优先 Reply-To，否则回复发件人，保留线程引用。支持富文本、固定签名、服务器版本化草稿及最多 10 个、合计 10 MiB 的附件。

点击发送授权该封人工回复；不套用开发信每日额度和营销时段，仍检查连接、账号暂停、身份及草稿版本。发送幂等，SMTP 接受、失败、未知和已发件箱副本状态分别记录；记录失败不重发，未知结果先核对。

已匹配企业及固定邮箱的实际往来进入业务记录，客户具体咨询由独立后台链路整理 T1；未匹配邮件不自动新建企业，人工回复不自动改变接待归属。后台增量收信已实现，自动回信仍待接入。当前限制见 [邮件沟通](../outreach-first-touch.md)。
