# 邮件原格式阅读及会话内人工回复

2026-10-27 用户确认在沟通中心还原邮件原有 HTML 排版，并保留纯文本切换；内嵌图片正常显示，外链图片由用户按封点击加载。升级后首次手动同步沿用原同步范围补回已缓存邮件的 HTML 与回复头，不清空原文、会话或本地已读状态。此决定扩展 [ADR-0013](0013-read-only-mail-conversations.md) 的只读边界。

会话内只提供单人“回复”，不提供回复全部；沿用当前会话邮箱，优先 Reply-To，否则回复发件人。回复编辑支持基础富文本、账号签名、附件上传及服务器草稿保存。附件最多 10 个，合计解码后不超过 10 MiB。原始邮件按账号及消息编号归并，发送正确引用原线程。

用户点击发送授权这一封人工回复。人工回复独立统计，不受本系统开发信每日额度、营销时段及首封计划审批限制；仍校验账号身份、连接及账号暂停。发送前保存幂等操作，SMTP 接受、失败、结果未知和已发件箱副本状态分别记录；归档或客户记录失败不能触发再次发信。结果未知须核对，不能自动重发。

客户和固定邮箱归属明确的实际往来进入客户沟通记录，保留实际状态。未匹配邮件不自动创建企业；人工回复不自动创建采购需求或改变接待归属。HTML 使用清理与隔离展示，邮件不取得主页面脚本权限。用户已授权三个已配置公司邮箱之间的技术互发测试，此授权不扩大到真实潜客。
