# 首封开发按已审核的品牌具体产品范围选择邮箱

2026-10-26 用户进一步明确三个品牌的产品分工，替代 [ADR-0011](0011-shared-sender-pool-for-first-outreach.md) 的不区分产品发件池：首封开发先用客户经营证据匹配具体产品，再依据已审核的官网产品覆盖选择对应邮箱，业务确认的范围以 [邮箱路由](../../agents/export-sales/mailbox-routing.md) 为准，账号容量仅用于适用范围内的调度。四个品类 Agent 是内部专业分工，不是公司完整产品目录，也不能把同一品类下的全部产品自动授权给某邮箱；官网暂不可访问不撤销有效业务确认，客户经营相关性也不证明采购意向。已准备邮件保留原发件账号与署名，覆盖或资料变化后重新核对草稿与批准，实际邮件归属不可改写；企业首封去重、既有往来的固定邮箱及共享目录协作继续有效，本轮仍只做首封主动开发，公司邮箱小批测试须共同检查后才可单独启动正式计划。
