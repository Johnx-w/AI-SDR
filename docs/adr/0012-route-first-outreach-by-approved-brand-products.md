# 首封开发按已审核的品牌具体产品范围选择邮箱

状态：有效且已有实现；2026-11-10 对照首封候选匹配与邮箱配置代码核对。

先按客户经营证据匹配具体产品，再按已审核品牌覆盖选择邮箱；额度只用于适用账号间的调度。品类画像不是完整供货目录，也不授权邮箱整个品类的产品。当前品牌业务范围见 [邮箱路由](../../agents/export-sales/mailbox-routing.md)。

官网暂不可读不撤销有效业务确认，客户经营相关性不证明采购意向。已准备邮件保留发件身份，覆盖或资料变化后重新核对；同企业跨联系人、账号和计划只安排一封首信，实际往来后沿用固定邮箱。

选择逐项产品覆盖，是为了保持对外品牌身份和供货依据一致。首封采用独立写作模块；回信自动接待仍需另行实现和授权，内部技术试发不产生客户开发许可。实现入口见 [邮件沟通](../outreach-first-touch.md)。
