# 删除触达计划时暂停来源获客任务

状态为已确认的待实施设计，2026-11-27 用户确认。

删除触达计划会结束该计划剩余首发和未回复跟进，并保留发送事实、结果核实和企业去重依据。若计划由获客任务生成，删除同时暂停来源获客任务及其关联定时安排，任务内显示暂停原因，等待人工重新启动或删除来源任务。

此决定扩展 ADR-0023 的来源联动规则。它让负责人从触达入口结束安排时能够停止继续产生同类任务，代价是删除操作会影响来源的客户搜索与研究，因此确认界面须列出受影响的来源任务、当前轮次及定时安排。来源人工重新启动后建立新的触达安排，旧计划在“已删除”中保持可查阅，执行步骤见[触达计划范围调整方案](../outreach-first-touch.md#触达计划范围调整方案设计中)。
