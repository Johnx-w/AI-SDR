# 删除触达计划时暂停来源获客任务

状态为已实现（本地隔离验收，尚未发布生产），2026-11-27 用户修正自动首发关闭及恢复规则。

删除触达计划会结束该计划剩余首发和未回复跟进，并保留发送事实、结果核实和企业去重依据。若计划由获客任务生成，删除同时暂停来源获客任务及其关联定时安排，将两处“获客后自动首发”持久化为关闭，页面取消勾选。任务内显示暂停原因并保留执行进度，等待人工恢复或删除来源任务。

此决定扩展 ADR-0023 的来源联动规则。它让负责人从触达入口结束安排时能够停止继续产生同类任务，代价是删除操作会影响来源的客户搜索与研究，因此确认界面须列出受影响的来源任务、当前轮次及定时安排。人工直接恢复时自动首发保持关闭，仅继续获客。用户重新勾选自动首发并保存后才建立新触达安排，其执行遵守来源当前状态。旧计划在“已删除”中保持可查阅，执行步骤见[触达计划范围与删除规则](../outreach-first-touch.md#触达计划范围与删除规则本地实现)，实际验证范围见[触达计划验收](../mail-automation/outreach-plan-acceptance.md)。

关闭状态须经过刷新、服务重启和异步检查点回写后仍有效。来源暂停及开关关闭尚未全部持久化时，删除显示处理中，旧触达持续停止提交。重新授权通过修订校验及幂等处理，防止过期操作恢复旧授权或重复创建新安排。

本地实现中，来源删除后的恢复请求携带页面读取的 `sourceControlRevision`，过期页面返回冲突；同次成功恢复的重试保留幂等结果。定时重新授权先持久化恢复记录，来源任务和定时安排全部保存后才通知触达；任一步失败或进程中断时撤回未完成授权，只恢复控制字段，保留企业处理进度及更新的来源决定。恢复记录在读取和后续来源操作前补齐。
