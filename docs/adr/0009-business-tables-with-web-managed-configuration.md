# 业务表保留企业、需求与沟通关系，系统配置由网页管理

状态：有效；2026-11-10 对照业务 Schema、产品资料及镜像同步代码核对。

五张核心业务表分别记录 T2 企业、T5 产品、T1 真实需求、T3 实际沟通、T4 后续追信。企业、会话、消息和需求分别关联；多个需求共享客户固定邮箱。T1 从真实来信自动整理，T4 只投影系统后续追信，网页不再维护手工业务台账，见 [ADR-0025](0025-automatic-business-records-with-read-only-followups.md)。

获客计划、任务及连接由网页和后端管理。T7 执行、T8 邮箱账号、T10 三份停用模板和 T11 实际搜索快照是协作镜像，不反向控制任务；具体规则见 [飞书填写规范](../new-feishu-bitable-filling-spec.md)。T12 与独立评分历史已取消。

公司产品资料与获客搜索词分别维护。未知参数、MOQ、交期及适用范围保持未知，产品实质修改后重新审核；产品审核不代替品牌覆盖、发信许可或附件外发权限。运行服务器 SQLite 保存主数据，飞书写入后核对读回。领导原 T5 已恢复原始字段，不再接收网页产品资料镜像；通用 T5 仅在 Schema 适用时同步。

这种归属减少配置、业务事实和执行状态的重复维护。建表和字段迁移仅用于受控初始化，不是日常启动步骤；当前字段、目标及备份见 [客户与产品数据](../customer-data.md)。
