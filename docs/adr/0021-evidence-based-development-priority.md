# 用已核实产品与经营角色决定开发优先级

2026-11-02 决定将初始开发顺序改为“高优先／常规开发”，同时单独展示匹配等级和有原文来源的优先线索。同一有效供货方向同时证实主营产品与对应供货角色时为高优先；其他已确认相关的企业为常规开发。官网通常不公开的经营年限、定制细节、采购方式或联系人不作零分扣减，也不自动生成补资料任务；明确不匹配的新发现企业不建客户档案，真实冲突继续阻断自动开发。

旧 A/B/C 与分数保留原规则版本供历史查看，不能机械映射到新等级，因为旧 B 同时包含高优先与常规客户。重新评价须依据已核实事实并备份现存快照；旧等级筛选的首封计划在更新前明确阻断，避免静默漏选或扩大收件范围。首封发送仍受联系入口和计划授权约束，未回复后的定期跟进另行设计。
