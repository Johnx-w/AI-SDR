# 真实沟通作为需求依据，跟进任务投影系统实际安排

状态：有效内容已按 ADR-0025 更新；2026-11-10 对照自动需求、真实邮件桥接和只读业务接口核对。旧手工默认流程已移除。

T1 只由已归属企业及会话的真实客户来信支持，保留原文和来源消息；官网画像、供货机会或我方发信不代替客户需求。同事项补充更新原需求，独立项目另建，歧义保留待核实原因。

实际收发保留原文、时间、参与方和渠道结果；草稿、失败或未知结果不冒充已成功发送，记录失败也不能触发重发。首次真实往来确定固定邮箱，内部技术测试不自动导入为真实业务。

T4 只记录已授权的后续追信及实际结果，首封和即时回信不建任务。历史人工安排不转为发信授权。任务只读，暂停、恢复和取消由所属发送计划控制；发送前重查最新回复、产品资料与账号身份。

服务器先持久化，飞书按稳定编号核对关联及读回，失败保留本地事实。保持证据和执行分离，是为了避免台账状态被当作实际联系证明。完整现行行为见 [客户与产品数据](../customer-data.md) 及 [ADR-0025](0025-automatic-business-records-with-read-only-followups.md)。
