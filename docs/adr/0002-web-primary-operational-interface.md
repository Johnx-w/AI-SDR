# 网页作为获客业务的主要操作入口

状态：有效；2026-11-10 对照网页路由、客户主档案与飞书同步代码核对。

网页管理获客计划、执行、产品资料、连接和邮件操作；服务器 SQLite 保存主档案、运行状态及真实历史，飞书仅供领导查阅报表，后台在推送时读取飞书以核对写入。网页业务内容只从项目数据产生，飞书中的新增、修改和删除均不导入。

选择单一操作入口是为了减少两处维护造成的状态冲突。日常需求与沟通由真实来信及收发自动整理，跟进任务只读；人工主要处理配置、资料和邮件例外。实现边界见 [客户与产品数据](../customer-data.md) 和 [架构与运行](../architecture.md)。
