# 每位客户固定一个官网邮箱并使用共享产品目录

2026-10-23 用户确认：同一办公室运营多个官网邮箱，三个已举邮箱只是一部分；这些官网对外保持独立，报价与签约共用一个交易主体。对尚未开始邮件沟通的客户，依据其需求和经审核的官网产品覆盖选择一个邮箱；客户从官网来信时沿用收件邮箱。开始沟通后，一个客户持续使用同一邮箱。官网没有展示客户后来询问的产品时，先查公司的总产品目录：有该产品便让对应品类 Agent 在内部辅助并由固定邮箱继续回复；总目录确认没有时才按该需求转人工。选择这个结构是为避免每邮箱复制四套画像、重复联系客户和在对外独立品牌之间切换身份；官网覆盖与公司可供产品、目录命中与已批准的规格声明分别判断。
