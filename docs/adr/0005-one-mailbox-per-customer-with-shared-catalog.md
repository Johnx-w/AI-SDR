# 每位客户固定一个官网邮箱并使用共享产品目录

状态：有效；固定邮箱与首封匹配已有实现，品类目录协作属于待实现的回信接待。2026-11-10 对照收发业务桥接及邮箱路由核对。

同一办公室运营多个对外独立品牌，报价和签约共用交易主体。首封按已审核的具体品牌产品覆盖选择邮箱，见 [ADR-0012](0012-route-first-outreach-by-approved-brand-products.md)；实际开始往来后保留客户固定邮箱，不因品类变化、账号空闲或人工接管更换身份。

自动接待接入后，固定官网未展示的新产品先核对公司总目录：确认有则由对应品类在内部支持并沿用原邮箱；确认没有则按该需求转人工；目录未知或查询失败先核实。目录命中不代表规格或商务内容已经获准外发。

这种选择避免重复客户历史和跨品牌切换。完整边界见 [邮箱路由](../../agents/export-sales/mailbox-routing.md)。
