# 宽泛收录企业并单独表达初始开发优先级

状态：已采纳（2026-10-24）

## 决策

企业主体、目标市场与窗饰相关产品线经来源核实后，保留为潜在开发企业。新增目标统计去重后实际写入并经飞书读回确认的企业数；既有档案更新、重复发现和待确认写入不计为新增。

A/B/C 仅表达初始开发优先级，基于已验证事实形成可解释的初评级。未知的持续经营、采购方式、采购量、联系人、海关记录或公司级联系入口列为资料缺项，不单独阻断入库或抹去初评级。缺少事实时不补分。每个成品、材料配件或样本方向分别记录，潜在业务关联不得描述成已确认采购意向。

官网主体与经营国家仍是收录基础校验。第三方贸易平台或市场的运营方地址和联系信息不归于商家。公开研究只读取有限数量的官网页面；达到合理边界后记录缺项并结束，不反复深挖难以公开取得的员工私人联系方式。已配置的海关、搜索和模型服务可用于真实研究。新增付费联系人数据库或邮箱服务须先由用户决定。

## 理由

过去以可交接条件作为新增目标，把资料完整度、联系入口和供货事实混成企业准入要求。由此可能漏掉确有窗饰业务、但尚未公开采购细节的潜客，也让初步销售优先级看起来像成熟交接或成交判断。拆分企业收录、供货机会、初评级和资料缺项，可以保留真实开发可能，同时清楚标注哪些事实已证实、哪些仍待沟通。

## 后果

目标进度只反映去重后新增档案数；执行明细另行展示更新、重复、评级和缺项。旧任务历史保留原计数及原始结果，不重写旧事实。未来邮件触达和回复可继续验证需求，但自动获客任务不代替该验证。
