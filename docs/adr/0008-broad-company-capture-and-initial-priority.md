# 宽泛收录企业并单独表达初始开发优先级

状态：有效；2026-11-10 对照当前准入、主库保存与 acquisition-v5.0 评级代码核对。

主体与相关产品经来源核实后，可保留为潜在开发企业；经营国家未知时留空并可入库，不能用搜索目标代填。已证实国家与目标市场不符仍排除；未公开采购量、经营年限、负责人或邮箱不单独阻止收录。

新增目标只计去重后实际写入并读回客户主库的新企业，飞书镜像状态单独核对。更新既有档案、重复发现与尚未确认的保存不计新增，历史轮次数量不因后续补录回算。

各供货方向独立形成 A/B/C、匹配等级及依据，现行规则见 [客户评级](../assessment.md) 和 [ADR-0022](0022-unified-abc-customer-grades.md)。普通官网缺项不默认转为人工补档要求；真实冲突仍阻止自动首发。官网研究有页面及预算边界，当前不包含海关自动获客。

选择宽泛收录是为了保留真实开发机会，将企业准入、联系准备和采购意向分别表达，避免把资料完整度或销售交接当作新增标准。
