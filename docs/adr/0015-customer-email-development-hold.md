# 企业级暂缓自动邮件，人工回复与实际沟通进度分别保留

2026-10-28 整理：当前产品行为与实现状态见 [现行主题说明](../customer-data.md)；以下保留决策形成过程及当时范围。

2026-10-28 补充：用户确认按实际业务事实自动联动网页开发进度。正式发送被服务商接受或已核实发出后为“已联系”，正常真实来信为“已回复”；需求必须引用同企业、同会话的真实来信或确认通话原文，进入规格澄清、报价、寄样、议价阶段，或已实际发送针对该需求的后续回复后，显示“跟进中”。草稿、失败、未知结果、自动回复、待办计划及官网画像不能推进状态。网页在读取列表、详情、导出及客户业务时统一计算，因此历史已保存事实同样生效，无需重放邮件。保留飞书原始状态及较后续的人工进度、成交和联系限制；本地暂缓继续优先显示，明确恢复后重新显示实际进度。该补充扩展下文仅覆盖暂缓的早期列表规则，不授予发送或恢复权限。

2026-10-27 用户确认并要求实施：网页在企业档案和已明确关联企业的邮件会话中提供暂缓／恢复入口，按同一家企业控制所有已关联联系人及计划的自动开发邮件和相关系统邮件跟进任务。暂停单个联系人容易被另一计划绕过，因此本期以企业为边界；人工收信、回复和实际沟通历史继续保留，人工回复、客户新来信及长期未回复均不自动改变暂缓决定。未关联或归属不唯一的会话先核对企业，不猜测归属。

暂缓必选原因，“其他”须填写说明，复查日期可选；本地持久化动作、时间、原因和“人工操作”，账号身份留待以后设计。复查按北京时间计算，到期仅在网页铃铛提示，查看不消除提醒；恢复、延期或清空复查日期后结束对应提醒。恢复须重新查看最新沟通并确认下一步安排，旧草稿需重新准备和审核，原任务单独核对恢复，不补发积压邮件；既有退订、飞书档案、邮箱和计划限制独立生效。

控制状态与飞书原始开发进度分别保存，列表只覆盖当前暂缓显示；暂停和恢复版本使旧草稿失效，提交 SMTP 前再核对客户表及当前控制。已经交付邮件服务商的发送不能保证撤回，仍记录实际结果。本期接入现有自动首次开发与系统跟进任务核验，后续自动跟进发信执行器另行设计。
