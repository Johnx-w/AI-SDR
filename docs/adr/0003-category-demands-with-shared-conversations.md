# 按品类拆分需求并在同一会话统一回复

状态：有效的待实现接待设计；2026-11-10 对照四品类维护源、1.3 Schema 与现有邮件代码核对。四品类自动回信尚未接通。

我方是从中国向海外 B 端买方出口窗饰产品的供货卖方。每项明确产品需求由透气窗、横百叶、其他室内成品帘或户外遮阳品类提供专业内容，同一来信在同一会话和固定邮箱中统一回复，不产生多个对外窗口。

政府、学校、医院等室内工程由 indoor 对外主责，横百叶由 venetian 提供产品支持；户外工程归 outdoor。品类、工程主责和人工接待归属分别判断。

单封商务审核与人工接管分别管理。有效资料、客户条件和接待配置均明确授权的标准商务内容，未来可按授权自动回复；现有 1.3 参考协议仍将具体商务内容作为单封待审草稿。超权限事项按需求或会话接管，其他独立需求仍可处理；真人明确交回前不自动恢复。

选择这一结构是为了共享客户历史并保留专业边界。完整目标和接入顺序见 [自动接待设计](../ai-sales-agent-design.md)，当前协议见 [会话协议](../../agents/export-sales/conversation-contract.md)。
