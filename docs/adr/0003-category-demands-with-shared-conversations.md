# 按品类拆分需求并在同一会话统一回复

2026-10-28 整理：当前产品行为与实现状态见 [现行主题说明](../ai-sales-agent-design.md)；以下保留决策形成过程及当时范围。

我方是从中国向海外 B 端买方出口窗饰产品的出口供货卖方。四个品类业务员均代表我方开展销售接待；海外进口商、经销批发商、组装加工企业、工程或机构采购方是买方。2026-10-22 用户核对完整方案后再次强调该交易方向，并确认其余方案。

同一封客户来信可能同时咨询百叶窗、透气窗等不同品类。2026-10-22 用户确认：每项产品需求交给对应的四类品类业务员提供专业内容，再在同一会话内组织统一回复。这样既保留各品类的专业边界，也能延续共同的客户历史；产品需求的拆分不产生多个对外回复窗口。

横百叶（木、复合木、PVC、铝、PS）归百叶窗品类，其他已列明室内帘归室内成品帘品类。政府、学校、医院等室内工程由室内成品帘业务员对外主责；涉及横百叶时，百叶窗业务员提供产品支持。户外工程由户外遮阳品类承接。

用户同时确认：常规产品答疑、需求收集和已确认样品政策介绍可以自动回复；正式报价、折扣、特殊交期和合同须人工确认。正式报价进入人工接管流程，人工确认报价后可选择继续人工跟进，或明确交回品类业务员自动接待；报价确认本身不自动恢复 AI 接待。触发人工接管时，先发送一次简短确认，再暂停相应的自动回复，由人工明确交回后恢复。

用户随后明确采用按需求分别接管：人工负责需要人工判断的需求及其后续沟通，其他独立的常规需求继续由 Agent 自动回复。人工处理后，可选择保留后续跟进责任，或明确交回 Agent；同一会话的统一回复要求不构成全部需求同时暂停的理由。涉及多项需求共同的报价、运费、整批交期和合同承诺，由人工统一确认，其他独立产品答疑仍按各自接待归属处理。

2026-10-23 关于正式报价一律人工接管及共同商务事项一律接管的决定，已由 [ADR-0006](../archive/2026-10-28/adr/0006-review-commercial-commitments-separately-from-handoff.md) 更新；本文件其余品类和统一会话决策仍适用。
