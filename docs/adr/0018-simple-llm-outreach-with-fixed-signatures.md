# 先跑通固定签名加 LLM 的自动开发流程

2026-10-27 用户纠正首期方向：先完成自动发邮件，品类业务员接入后续再处理。新建触达计划由 LLM 根据客户经营依据与邮箱负责的已确认产品范围生成基本主题、正文，服务端附上既定发件身份和签名，启动后直接生成、排队和发送；不要求预先填写介绍，不设置准备样稿或逐封审批步骤。计划启动本身是该范围和数量的发送授权，连接验证、客户暂缓与勿联系、企业和地址去重、发件品牌覆盖、发送限额和发送前状态核对继续执行。首轮从已有客户库选择合适对象，总计测试 20 封，不为了达到数量向用途不合适的地址发送。具体价格、库存、认证等未确认能力不进入基础介绍。这个决定更新 ADR-0016 的首期业务员接入安排；旧计划与记录保留原生成方式，新计划默认走简化流程，收发结果未知时仍不自动重发。
