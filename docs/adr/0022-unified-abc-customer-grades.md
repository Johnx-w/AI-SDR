# 统一客户评级为 A/B/C

状态：有效且已有当前规则实现；2026-11-10 对照 acquisition-v5.0、当前评估存储与客户镜像核对。

网页、SQLite 与飞书采用同一份当前 A/B/C：同一供货方向的主营产品及对应供货角色均有依据为 A，产品已核实但主营或角色优先线索较弱为 B，其余待核实或较弱机会为 C。明确不匹配的新企业不入库，既有档案保留真实历史并移出日常开发视图。

各方向独立取证，年限、采购量或联系资料未知不补造事实，也不通过总分阈值机械排序。只保留最新评估和真实来源，不保留旧评级兼容执行分支。实际云端回填是否完成须核对运行数据，不能由源码或这份决定推断。

这种统一避免不同页面和镜像采用不同标签。A/B/C 均可作为首封候选，实际发送仍须通过身份、联系邮箱、产品依据及计划授权。现行细则见 [客户评级](../assessment.md)，镜像边界见 [ADR-0024](0024-align-feishu-business-mirrors.md)。
