# 统一客户评级为 A/B/C

2026-11-02 决定以 A/B/C 作为客户库和新评估的统一初始开发评级：同一供货方向有已核实主营产品及供货角色为 A，产品匹配已确认但优先线索较弱为 B，信息待核实或机会较弱为 C。明确不匹配的新企业不入库；真实经营事实冲突仍阻断自动首封。A/B/C 均可进入首封候选，但实际发送仍须满足身份、产品依据、可用商务邮箱和计划授权。

现有 `acquisition-v4.0` 客户已保存逐条官网证据，按产品与角色维度重新投影为 A/B/C，保留原始飞书评级和理由以供核对；没有这些证据的旧值不机械升级。此选择避免批量重写飞书业务字段，也避免把旧分数误当作当前评级。已保存的“高优先／常规开发”筛选计划需人工更新，防止收件范围静默变化。
