# 统一客户评级为 A/B/C

2026-11-02 决定以 A/B/C 作为客户库和新评估的统一初始开发评级：同一供货方向有已核实主营产品及供货角色为 A，产品匹配已确认但优先线索较弱为 B，信息待核实或机会较弱为 C。明确不匹配的新企业不入库；真实经营事实冲突仍阻断自动首封。A/B/C 均可进入首封候选，但实际发送仍须满足身份、产品依据、可用商务邮箱和计划授权。

2026-11-05 用户确认网页、SQLite 与飞书统一使用最新评级规则，撤销此前仅改变网页展示而保留飞书旧评级值的取舍。旧评级值从项目中清除，不为这些旧值新增备份；如需说明历史，最多保留一份归档 Markdown 文档。实际经营事实与原始证据继续作为当前评级的依据，不以旧标签机械替代重新判断。

此更新记录已确认的目标，尚未完成旧值清理和数据回填；字段及后续同步规则继续讨论，相关边界见 ADR-0024。
