# 自动整理业务记录，客户页面只保留只读追信任务

状态：有效且已完成本地实现；2026-11-10 对照自动需求提取、追信执行器、只读页面与业务 API 核对。云端版本须另行核验。

2026-11-10 决定以自动运行为默认：删除独立采购需求、重复沟通记录页面及全部手工台账流程，沟通中心统一阅读往来；真实来信自动生成 T1，实际收发继续镜像 T3，T4 和只读任务页只反映系统后续追信及真实结果。保留邮件证据、固定邮箱、需求关联和历史数据，是为了满足领导飞书表格及后续自动化；这些后台事实不要求业务员再次录入，首封、即时回信和测试任务不充当追信。此决定替代 ADR-0010 的手工默认流程及 ADR-0024 中“不自动创建采购需求”的限制，更新 ADR-0009 的 T4 范围及 ADR-0019 的页面分工；首封未回复的 72/168 小时规则和停止条件沿用 [当前设计](../ai-sales-agent-design.md)，产品资料、邮件发送授权及证据要求继续有效。
