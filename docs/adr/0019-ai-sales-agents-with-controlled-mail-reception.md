# 四品类业务员共用运行程序，按独立授权接入邮箱回信

状态：有效的待实现正式接待设计；2026-11-10 对照四品类参考协议及当前邮件代码核对。正式接待页面、配置与真实自动回信链路尚未接通。T1/T4 自动产生规则见 [ADR-0025](0025-automatic-business-records-with-read-only-followups.md)。

2026-10-28 将 [AI 业务员与邮箱自动接待设计](../ai-sales-agent-design.md) 定为后续实现依据：侧边栏增加「AI 业务员」，管理四个固定品类角色、接待范围、自动回复权限与人工交接；复用现有模型连接、邮件收发、客户会话及产品资料，以一套运行程序按需求加载专业规则并在原邮箱统一回复。这样保留品类专业分工，同时避免独立 Agent 环境、重复客户历史和多个对外回复窗口。

首次开发继续执行 ADR-0018 的简化 LLM 流程；正式回信接待将使用单独配置和授权，首期覆盖已明确关联企业及固定邮箱的新来信，历史导入只供上下文。资料完备且接待配置明确授权的标准商务内容才可自动回复；有依据但未获自动权限的内容进入单封审核，超权限事项按需求或会话接管。该设计与 [ADR-0017](0017-automatic-sending-with-confirmed-information.md) 的授权原则一致，不将首封计划授权扩展到来信接待；人工收发保留。

2026-10-28 的决定只统一文档和提示词文案；自动接待页面与运行链路仍待实现。现有来信协议 1.3 仅为参考，缺少新授权上下文时保留商务草稿单封审核；正式接入须同步升级至 1.4 并实现系统校验。首封未回复自动追信已按 ADR-0025 在本地实现，产品图纸提取候选已支持；自动技术回复及附件仍待后续接入。
