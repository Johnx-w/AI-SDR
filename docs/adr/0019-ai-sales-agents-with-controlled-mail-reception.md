# 四品类业务员共用运行程序，按独立授权接入邮箱回信

2026-10-28 将 [AI 业务员与邮箱自动接待设计](../ai-sales-agent-design.md) 定为后续实现依据：侧边栏增加「AI 业务员」，管理四个固定品类角色、接待范围、自动回复权限与人工交接；复用现有模型连接、邮件收发、客户会话及产品资料，以一套运行程序按需求加载专业规则并在原邮箱统一回复。这样保留品类专业分工，同时避免独立 Agent 环境、重复客户历史和多个对外回复窗口。

首次开发继续执行 ADR-0018 的简化 LLM 流程；回信接待使用单独配置和授权，首期覆盖已明确关联企业及固定邮箱的新来信，历史导入只供上下文。资料完备且当前接待配置明确授权的标准商务内容可自动回复；有依据但未获自动权限的内容进入单封审核，超权限事项按需求或会话接管。该设计统一 ADR-0006、0017 的授权与接管原则，不将首封计划授权扩展到来信接待；企业暂缓同样阻止未来自动回信，人工收发保留。

本轮只统一文档和提示词文案；自动接待页面与运行链路仍待实现。现有来信协议 1.3 仅为参考，缺少新授权上下文时保留商务草稿单封审核；正式接入须同步升级至 1.4 并实现系统校验。自动追信、图纸解析及自动技术附件作为后续范围。
