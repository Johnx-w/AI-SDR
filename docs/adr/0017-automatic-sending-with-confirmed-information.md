# 根据已确认资料和计划授权免除逐封审核

2026-10-28 整理：当前产品行为与实现状态见 [现行主题说明](../ai-sales-agent-design.md)；以下保留决策形成过程及当时范围。

2026-10-27 用户确认：负责人确认产品资料的对外使用范围，并授权触达计划后，符合条件的首次开发信可由系统自动匹配、生成、检查和发送，无需逐封人工批准；后期资料齐全时，具体报价、MOQ、库存和交期等适用商务内容也可免逐封审核。选择以资料确认和计划授权作为自动发送依据，是为了让持续开发无需重复人工审批，同时将对外声明限制在公司明确批准的事实和范围内；模型自行判断资料完整不产生发送授权。

资料完备按本封邮件所需事实判断，不要求整个产品库的字段全部填完：缺少价格或交期时，仍可发送仅引用已确认产品信息的介绍；没有依据的卖点省略，基本产品或品牌范围不明确时暂停。此决定更新 [ADR-0006](../archive/2026-10-28/adr/0006-review-commercial-commitments-separately-from-handoff.md) 中具体商务承诺一律逐封审核的要求，保留人工审核与人工接管的区别，以及超出已授权标准范围的事项按既有规则处理；它不扩大 [ADR-0016](../archive/2026-10-28/adr/0016-professional-agents-for-first-outreach.md) 的首期实施范围，也不代表当前自动来信接待或追信已获启用。

供货资料完备不代表客户采购条件已明确。首封可以引用附带完整适用条件的已确认标准报价，但不能将其表述为已经适用于该客户的最终报价；需要尺寸、数量等信息才能计算的价格先询问缺项。价格、库存和交期等易变信息按资料规定的有效期或最新核实依据使用，过期后停止引用，仍可发送依据有效资料的产品介绍；稳定的产品种类、材料等事实不要求每日重复确认。

资料新版本确认后，受影响但尚未发送的邮件重新生成并检查，在原计划授权范围内自动继续，无需逐封批准；扩大产品范围、更换发件品牌或扩大计划授权范围须重新确认计划。已发送邮件保留原始内容和记录，资料更新不能改写已经作出的对外陈述。
