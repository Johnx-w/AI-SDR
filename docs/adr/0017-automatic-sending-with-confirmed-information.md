# 根据已确认资料和计划授权免除逐封审核

状态：有效；首封基础介绍已有实现，标准商务自动回信属于待实现设计。2026-11-10 对照写作校验、计划控制及 1.3 参考协议核对。

负责人批准产品资料对外使用范围并启动触达计划后，范围内的基础首封可自动匹配、生成、检查和发送，无需逐封审核。资料完备以本封实际引用的事实为准，不要求填满整个产品库；模型判断不产生业务批准。

当前首封写作只作基础产品介绍，程序拦截价格、MOQ、库存、认证、交期、运费和付款等声明。已确认商务资料不绕过该限制。标准商务自动回信须按 [自动接待设计](../ai-sales-agent-design.md) 后续实现资料适用、客户条件和逐项商务授权；现有 1.3 参考协议缺少该上下文，仍形成单封待审商务草稿。

资料实质变更使相关未发内容重新核验；在原许可范围内的新版本批准后可重做，已发送原文保持不变。手动触达计划扩大产品、市场或更换品牌须重新确认；[ADR-0023](0023-acquisition-scoped-automatic-first-touch.md) 单独规定获客自动首发可持续纳入最新已审核产品和可用邮箱。

这种选择让重复性基础开发无需逐封批准，同时保持资料审核、发信授权、单封审核和人工接管各自的含义。首封、追信与回信接待分别启用和授权。
