# 获客开发优先级规则 v1

状态：历史草案，未启用。2026-10-21随后按用户提供的真实成交/沟通样本提出 [评分v2](acquisition-scoring-v2.md)，供用户检查。本文件保留原演算，不应与v2档位混用。

## 评分对象和用途

对“某家企业 × 某一供货方向/产品族”的供货机会评分。成品、材料配件、样本展示分别评价，同一企业可以有多个结果。

总分表示开发优先级，帮助选择值得优先沟通的机会。它不表示成交概率、当前采购意向或预计利润金额。利润潜力先用供货适合程度、规模与持续采购可能性等证据判断；没有我方成本和订单条件时不编造利润。

企业列表显示其仍可开发机会中最高的当前等级及对应方向；已经排除、存在硬性障碍或资料失效的机会不参与企业最高等级汇总。

## 先检查可开发性

以下判断先于总分，不能靠其他维度加分抵消：

- 仅个人消费、非经营主体：不进入企业开发队列。
- 明确不经营、不采购且与目标产品无关：排除该供货机会。
- 已核实无法满足的强制规格/供应商条件，或已知订单条件低于我方已配置的最低接单经济性：暂不开发该机会，保留依据。
- 不是企业本人的官网/联系方式、主体存在冲突：待核实。
- 工厂、当地门店、服务家庭消费者、网站简单本身都不是排除理由。
- “无进口记录”“无公开采购需求”“无采购负责人”“规模未知”本身不是排除理由。

MOQ、成本、运费或利润门槛尚未配置时，规则不自动假设某家企业薄利；标记“订单经济性待核实”。供应商条件中的未知也不伪装成已确认障碍。

## 五项计分，共100分

业务适合程度与商业潜力占80分，近期机会信号占20分。每项选择证据支持的最高一档，不叠加同一项的多个档位。

| 维度                 | 满分 | 档位                                                                                                                                                                                                                                                                                                                                                                                                        |
| -------------------- | ---: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P 产品与供货契合     |   30 | **30**：目标品类属于其主营/稳定产品线，或明确外采的材料部件直接用于其主营制造；**20**：有明确经营/项目/采购关联，但只是副线或局部机会；**10**：只证实邻近行业，具体品类关联弱；**0**：明确不匹配；**未知**：资料不足                                                                                                                                                                                        |
| R 采购路径与经营模式 |   25 | **25**：目标方向有明确进口、外采、第三方制造/供货或寻找生产商的证据；**20**：明确相关批发、分销、经销、进口贸易或品牌渠道经营，但具体货源未公开；**15**：相关产品的企业零售、工程/成套采购等经营模式支持潜在企业采购，但外采方式未核实；**10**：有明确仅提供安装/维修、不提供产品或项目供货的经营证据，采购路径偏弱；**0**：已确认没有适用采购路径；**未知**：经营方式不清，不能仅凭没找到销售页面认定10或0 |
| S 规模与持续采购潜力 |   25 | **25**：同一评价主体可核实≥10个经营网点、≥20家实际经销商，或近365天≥12票已核实的相关进口；**18**：2—9个经营网点、5—19家实际经销商，或近365天3—11票已核实的相关进口；**12**：可核实供货/经销网络或持续项目业务存在，但规模未量化；**6**：明确单点小范围经营，尚无扩展/持续批量采购证据；**未知**：只有地址或“全国配送/最大之一”等宣传，规模不可核实                                                          |
| I 近期采购活动       |   15 | **15**：近180天企业自己发布与我方供货相关的询价、招标或寻找供应商信息；**10**：近180天有主体已匹配的相关进口记录；**5**：相关进口记录距今181—365天；**0**：本次研究未检出适用信号或已超出窗口；缺失/无覆盖/未匹配另行标注                                                                                                                                                                                   |
| E 产品或业务扩张     |    5 | **5**：近180天有明确事件日期的相关新产品线、渠道扩张或新商业项目；**0**：本次未检出适用信号。促销、版权年份、普通网页修改时间不计                                                                                                                                                                                                                                                                           |

### 计分解释

- R的15/20档代表经营模式提供了采购可能性线索，不把推断写成“已发生采购”或“正在找中国供方”。单独出现supplier一词不足以证明分销/外采。
- S的6档必须有明确的经营范围/单点业务证据。一个地址或没有查到其他网点，不能直接记为小客户。
- 实体门店不适用于纯线上企业时，不把“没有门店”记为小规模；可以用其经销、实际经营网络或进口证据，仍没有证据则S未知。
- 不把集团总规模自动套到旗下某个独立采购主体，也不把服务城市或移动展厅覆盖城市算作实体门店。
- S的进口票数必须能按唯一提单/记录语义去重，明确观察时间窗、产品相关性和覆盖范围；现有2234行Excel缺少提单标识，不能用行数触发3票/12票档位。重量单位和箱量口径未确认前也不参与规模换算。
- I计算采购活动新近性，S计算持续性/规模，两者用途不同；同一事件不得在I内部叠加多个档位。
- 已匹配主体和产品的真实采购/进口也能证明R的25档；R证明路径、I衡量新近性，不能一边使用真实采购信号加I分，一边仍把同方向的采购路径记为未知。记录有矛盾时先核实，不强行拼分。
- 新品若与旧产品线只是换名、页面首次被抓取或无事件日期，不加E分。同一采购事件不能同时冒充扩张事件取得E分。
- 某条证据否定特定规格适配时，先应用可开发性判断，不允许进口量或企业规模把不适配机会抬成A级。

## 未知项和等级

未知项保存为未知，不写成“已证实0分”。没有证据的项暂不贡献分数，界面显示已获支持的分数及缺项；采购活动“本轮未检出”不解释成企业没有需求。

| 等级/状态     | 条件                                                                                             | 默认动作                                 |
| ------------- | ------------------------------------------------------------------------------------------------ | ---------------------------------------- |
| A 高优先级    | 总分≥75，P≥20、R≥15、S≥12均有证据，且无硬性开发障碍                                              | 资料齐备后优先交接                       |
| B 可开发      | P≥20且R≥15，总分55—74；同样满足P/R门槛且总分≥75，但规模未知或低于A要求时暂列B                    | 资料齐备后交接；规模未知明确展示         |
| C 暂缓        | P/R已知但任一低于A/B门槛；或P/R门槛满足、S已知且总分<55                                          | 暂不进入默认销售接手队列，保留机会及原因 |
| 待核实/未评级 | P或R未知；或P/R门槛均满足、总分<55且S未知；或存在主体/关键证据冲突、已公开的强制适配条件尚未核实 | 优先补关键资料，不能因缺资料自动评C      |
| 暂不开发      | 可开发性检查发现明确障碍或负责人有理由排除                                                       | 从当前机会交接队列移出，保存依据         |

程序按固定顺序判定：①已确认不可开发或负责人排除，归暂不开发；②主体/关键证据冲突、公开强制适配条件待核实或P/R未知，归待核实；③P/R均已知但P<20或R<15，归C，无论S是否未知；④P/R门槛满足、S未知，分数≥55归B，否则待核实；⑤P/R/S已知，满足A条件归A，其余总分≥55归B，否则C。P=0或已确认R=0在第一步排除该方向。这个顺序优先于表格阅读顺序，不允许其他加分越过可开发性和P/R门槛。

同等级先按分数排序，再按缺失项更少、证据更新鲜排序。不同供货方向不把维度混在一起凑高分；人工调整优先级必须保留理由、操作人及原系统结果。

## 联系准备情况独立判断

公开采购经理、邮箱数量或网站好看都不增加商业潜力分。联系准备与商业分数分别展示。

进入可交接队列的条件：

1. 企业身份与档案归属已核实，未处于疑似重复/关键事实冲突。
2. 至少一个当前机会为A或B，且P/R门槛满足、无硬性障碍；已知的我方产品条件不与其需求冲突。
3. 至少一种有来源的公司级商业邮箱、办公电话或联系表单。入口属于该企业，不是承运人/通知方等无关角色。
4. 资料包含机会理由、来源及日期、未知项、建议沟通切入点；已有沟通历史能够看到。

“公开发现/格式检查通过”与“已确认可投递/已接通”分别记录；第一版不靠发送测试消息确认联系方式。普通电话不能自动标为WhatsApp，采购岗位姓名也不等于个人邮箱或最终采购权。

业务分高但联系资料不足：保留高分，状态待补全，不计新增可交接目标。没有采购经理但有公司级入口：可满足联系条件。

## 逻辑对照例（构造示例，不是真实客户）

- P30/R25/S25，未检出近期信号：80分A。因此无海关或公开近期需求不自动降为不可开发。
- 同上80分，但没有任何联系入口：仍为A，状态待补全，不计新增交接数。
- 进口频繁、规模很大，但产品明确不相关：该方向排除，不靠总分进入队列。
- P30/R15/S6，未检出近期信号：51分C；若之后出现有日期且相关的真实采购需求，R同时获得明确采购路径证据升25、I取15，总分76。因S仍为6、不满足A的规模条件，归B并记录变化，不能仅按总分升A。
- 只有一个地址，没找到其他规模资料：S未知；不能把它套入上一例的6分。

## 版本、刷新和启用

- AI只提取、归纳带来源证据的事实和提出机会解释；程序依据已批准的版本选择档位和算分。存在歧义则留待核实，不让模型补齐想象。
- 每次评估保存机会ID、版本、五项档位、支持证据、未知项、障碍及评估时间；主档只显示当前摘要。
- 人工规则变更先预览对现有样本/客户的影响，确认后发布新版本；旧评估不覆盖，新版本重评另存历史。
- 新证据、身份修正、供货方向变化、证据过期或规则升级触发对应机会重评；未改变的输入复用已有结果。
- 建议初始画像/联系研究复用周期统一30天，可配置。事件时效使用事件日期和评估日期，不使用抓取日期冒充事件日期。
- 用户检查本版后再实现、试运行并启用；首批验收记录实际产出与业务反馈，未来调整有依据且保留版本，不自动学习改变权重。
